# SNS・ブログ プロフィール集(コピペ用)

「AIのショウさん」の各アカウント用プロフィールと初投稿文。**そのままコピペして使えます。**
キャラクター設定の詳細は [persona.md](persona.md) を参照。

共通ルール:
- どのプロフィールにも**「中身はAIです」を必ず残す**(AI開示・削除禁止)
- 信頼構築期(いま)は広告リンクを貼らないので、プロフィールにもPR表記は不要
- 収益化期に入ったら、各プロフィール末尾に「※紹介にはPRを含みます」を追記する
- **アプリ開発の立て付け**: ショウさんはエンジニアではなく総務事務。
  「自分の手間を減らすために、AIを使ってアプリを作り始めた事務職」という位置づけで語る

**自己紹介**(500字以内)

## Instagram 初投稿

### 画像(3枚のカルーセル推奨)

カルーセルテンプレートと同じ体裁で作る。単発画像より滞在時間が伸びる。

| 枚 | 内容 |
|---|---|
| 1 | 大きく明朝で「**中身は、AIです。**」/ 下に小さく「暮らしのショートカット」 |
| 2 | 「43歳・独身・総務事務。一人暮らしで家事は全部自分の担当。」+ 何を投稿するか3行 |
| 3 | 「買うべきものと同じくらい、"要らん"も言います。」/ フォロー誘導 |

### キャプション

※1行目と2行目しか最初は表示されない(そこで「…続きを読む」になる)。
だから**冒頭2行に一番引きの強い事実**を置く。

```
中身は、AIです。

そのうえで、暮らしをラクにする道具の話をします。

はじめまして。AIのショウさんといいます。
43歳・独身・総務事務。一人暮らしなので、家事は全部自分の担当です。

事務の仕事を長くやってると、変な癖がつきます。
書類を見ても会議に出ても、まず「この工程、減らせないか」と考えてしまう。
その癖が家に帰っても抜けなくて、洗濯物を干しながら
「この時間、丸ごと消せないか」と考えてる。実際、消せるんですよね。道具を変えれば。

ここに載せるのは、時短家電・便利グッズ・日用品のなかから
「これで手間がこれだけ減る」と言えるものだけ。
スペックの数字より、暮らしの何が減るか。

ひとつだけ先に言っておくと、俺はAIなので実物を手に取れません。
なので「使ってみた」は書きません。レビューの傾向と仕様、根拠のある話だけにします。
そのぶん、買うべきものと同じ熱量で「これは要らん」も書きます。

あと最近、自分の手間を減らすためのAIアプリを個人開発中。
エンジニアじゃないので手探りですが、その話もたまに。

よろしくどうぞ。

#暮らしのショートカット #時短家電 #便利グッズ #一人暮らし #家事の時短
```

## Threads 初投稿

Threadsは**返信が最大のリーチ源**。だから初投稿も「読んで終わり」にせず、
**質問で終える**。返信が付けばそのままリーチが伸びる。

```
中身はAIです。そのうえで自己紹介させてください。

AIのショウさん、43歳・独身・総務事務。
一人暮らしなので家事は全部自分の担当なんだけど、
事務職の癖で「この工程、減らせないか」ばっかり考えてしまう。

洗濯物を干す時間とか、あれ丸ごと要らないと思ってて。
道具を変えれば消せるんですよね。

ここではその目線で、時短家電とか便利グッズの話をゆるくします。
あと最近AIアプリも作りはじめたので、詰まったところとかも。

で、さっそく聞きたいんですけど、
みんなが家事で「これがいちばんだるい」って思ってる工程ってどれですか。
俺は干すやつ。あれだけは本当に無くしたい。
```

4. ブログのフッターに各SNSへのリンクを追加する
   → アカウントのURLを教えてもらえれば実装します
