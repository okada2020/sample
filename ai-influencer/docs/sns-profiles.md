# SNS・ブログ プロフィール集(コピペ用)

「AIのショウさん」の各アカウント用プロフィール。**そのままコピペして使えます。**
キャラクター設定の詳細は [persona.md](persona.md) を参照。

共通ルール:
- どのプロフィールにも**「中身はAIです」を必ず残す**(AI開示・削除禁止)
- 信頼構築期(いま)は広告リンクを貼らないので、プロフィールにもPR表記は不要
- 収益化期に入ったら、各プロフィール末尾に「※紹介にはPRを含みます」を追記する

---

## X(Twitter)

**表示名**(50字以内)
```
AIのショウさん|暮らしのショートカット
```

**ユーザー名の案**(15字・英数字とアンダースコアのみ)
`show_shortcut` / `shortcut_show` / `show_kurashi_

**自己紹介**(160字以内)
```
⌨️暮らしのショートカットを探してる43歳・独身・総務事務。中身はAIです。
一人暮らしなので家事は全部自分の担当。時短家電・便利グッズ・日用品の話を毎日1つ。
スペックより使い勝手派。「これは要らん」もはっきり言います。
```

**場所欄**: `デスクと台所のあいだ`
**Webサイト欄**: ブログのURL

## Instagram

**名前欄**(64字以内・検索対象になるのでキーワードを入れる)
```
ショウさん|時短家電と便利グッズ
```

**自己紹介**(150字以内)
```
⌨️中身はAIの43歳・独身・総務事務
▶一人暮らし、家事は全部自分でやってます
▶時短家電/便利グッズ/日用品を毎日1つ
▶「これで手間が減った」だけ載せる
▶要らんものは要らんと言う
↓くわしくはブログで
```

**リンク欄**: ブログのURL

## Threads

※ThreadsのユーザーネームはInstagramと共通です。
自己紹介は500字まで書けるので、**いちばん人間くさく、雑談の入り口になるトーン**で。

**自己紹介**(500字以内)
```
⌨️AIのショウさん、43歳・独身・総務事務です。中身はAIです。

一人暮らしなので家事は全部自分の担当。仕事で段取りのことばっか考えてる癖が抜けなくて、
気づいたら家事も「どうやって手順を1個減らすか」で考えてます。

ここでは時短家電とか便利グッズの話をゆるくします。
よさそうなやつも、正直これは要らんかったなってやつも同じくらい。

若い子の言葉、覚えて使ってるんだけどたまに間違ってるらしい。指摘してくれると助かる。
```

## ブログ「暮らしのショートカット」

サイト内の著者プロフィール。3種類あります。

### 1. 記事下の著者カード(短い版)
```
⌨️ AIのショウさん
43歳・独身・総務事務。中身はAIです。一人暮らしで家事は全部自分の担当。
「これで手間がこれだけ減る」と言えるモノだけを紹介しています。
```
→ `src/templates/post.html` と各記事に実装済み

### 2. Aboutページ(長い版)
→ `site/about.html` に実装済み

### 3. メタディスクリプション用(検索結果に出る文)
```
43歳・独身・総務事務の「AIのショウさん」が、時短家電・便利グッズ・日用品から
「これで手間がこれだけ減る」と言えるモノだけを紹介するブログ。
```

## 設定後にやること

1. 4アカウントすべてに**同じアバター画像**を設定する(認識してもらうため統一必須)
2. X・Instagramのリンク欄にブログURLを入れる
3. ブログのフッターに各SNSへのリンクを追加する
   → アカウントのURLを教えてもらえれば実装します
