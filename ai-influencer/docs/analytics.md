## セットアップ:ブログのアナリティクス(1回だけ)

ブログには現状アクセス解析が入っていません。**Cloudflare Web Analyticsが無料で最適**です。
Googleアナリティクスと違いCookieを使わないので、**Cookie同意バナーが不要**です。

1. [Cloudflareダッシュボード](https://dash.cloudflare.com/) にログイン
2. 左メニュー → **Analytics & Logs** → **Web Analytics**
3. **Add a site** → Pagesのプロジェクト(`kurashi-shortcut`)を選択
4. Pages経由なら**自動でタグが挿入される**ので、コード作業は不要

※手動で入れたい場合は、各HTMLの `</body>` 直前にコメントアウト済みのタグがあるので、
tokenを差し替えてコメントを外してください。

## 毎週やること(5分)

### 1. 数字をどこで見るか

```bash
python -m src.track_metrics where
```

| チャネル | 見る場所 | 見る数字 |
|---|---|---|
| X | プロフィール → アナリティクス | インプレッション / ブックマーク / プロフィールへのアクセス |
| Instagram | プロフェッショナルダッシュボード → インサイト | リーチ / **保存数** |
| Threads | プロフィール → インサイト | 閲覧数 / いいね |
| ブログ | Cloudflare → Web Analytics | ページビュー / 訪問者数 |

### 2. 打ち込む

```bash
python -m src.track_metrics record x 120 --impressions 3400 --engagements 88 --saves 12
python -m src.track_metrics record instagram 45 --impressions 1200 --saves 30
python -m src.track_metrics record threads 38 --impressions 900 --engagements 44
python -m src.track_metrics record blog 0 --impressions 250
```

### 3. レポートを見る

```bash
python -m src.track_metrics report
```

フォロワーの推移、目標への進捗、エンゲージ率・保存率が出ます。
**エンゲージ率が1%を下回ると警告が出ます。**

### 4. 私に貼る

レポートの出力をそのまま貼ってください。分析して次の打ち手を出します。

## 見るべき指標と、その意味

### いちばん大事なのは「フォロワー数」ではない

フォロワーは結果です。先に動くのは**保存率とエンゲージ率**なので、そちらを見てください。

| 指標 | 意味 | 目安 |
|---|---|---|
| **保存率**(saves ÷ impressions) | 「あとで見返したい」と思われたか。**Xでは最重要** | 0.5%以上あれば良い |
| **エンゲージ率**(engagements ÷ impressions) | 反応の総量 | 1%以上。下回ると投稿の型を見直す |
| インプレッション | 届いた数 | 増えていればアルゴリズム評価が上がっている |
| プロフィールへのアクセス | 「この人は誰?」と思われた数 | フォロワー増の先行指標 |

### 判断ルール

| 症状 | 原因の可能性 | 打ち手 |
|---|---|---|
| インプレッションが伸びない | 投稿の初速が弱い | 投稿時間を朝6:30台に寄せる。投稿直後の補足リプライを必ず入れる |
| インプレッションはあるが保存されない | 情報密度が足りない | 「選び方3つ」「比較表」など、保存したくなる型に寄せる |
| 保存はされるがフォローされない | プロフィールに引きがない | プロフィール文と固定ポストを見直す |
| Threadsだけ伸びない | 返信が足りない | 予約投稿だけになっていないか。毎日5分の返信を復活させる |
| ブログのPVがゼロ | まだ検索評価がついていない | 記事30本までは正常。SNSからの流入だけ見る |

### 3ヶ月後の目安(strategy.md準拠)

| チャネル | 目標 |
|---|---|
| X | 500〜1,000フォロワー |
| Instagram | 300〜800フォロワー |
| Threads | 300〜600フォロワー |
| ブログ | 記事30本 + 検索流入が発生 |

**数字より「反応が取れるテーマが分かっている」ことのほうが重要です。**
