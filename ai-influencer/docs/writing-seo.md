# 記事の書き方とSEO・SNSの運用指針

調査(2026年8月時点)にもとづく実践ルール。迷ったらこのファイルに従う。

---

# 1. 記事の書き方

## リード文の4ステップ(いちばん重要)

読者はリード文で「この記事を読むか」を判断する。
**平均エンゲージメント時間が10秒以下の記事は、リード文に問題がある**とされる。

| 順 | 要素 | ショウさんの場合 |
|---|---|---|
| ① | **悩みに共感** | 「寝る前に挿し忘れて、朝の充電が30%しかない」 |
| ② | **結論を先に出す** | 「これ、スマホじゃなくて充電器側の出力不足が原因なことが多い」 |
| ③ | **なぜ自分が言えるか** | 「一人暮らしで家事は全部自分の担当」「事務職で段取りばかり考えてる」 |
| ④ | **読むと何が得られるか** | 「今日は見るとこを3つだけに絞って書く。ここだけ見れば外さない」 |

※ショウさんは実体験が使えないので、③は**立場と視点**で担保する。
「毎日この目線で考えている人間(AI)が整理した」という形にする。

## 見出しの作り方

**読者の多くは本文を読まず、見出しだけを流し読みする。**
だから見出しは「見出しだけ並べて意味が通る」状態にする。

悪い例(意味が通らない):
```
チェック1
その2について
まとめ
```

良い例(見出しだけで記事が要約されている):
```
チェック1: 出力(W数)は「20W以上」が目安
チェック2: 規格は「USB PD対応」を選ぶ
チェック3: ポート数は使い方から逆算
正直、こういう人は要らない
```

## 記事の型(この3つを使い回す)

| 型 | 構成 | 狙い |
|---|---|---|
| **選び方型** | 悩み→結論→3ポイント→要らん→まとめ | 検索流入の主力 |
| **要らん型** | 逆張りの結論→効かない人→効く人→代替案 | 競合が少なく信頼が付く |
| **段取り型** | 家事の工程分解→どこが無駄か→道具の話 | 商品を出さない読み物。ファン化 |

## 必ず入れる要素

- 数字を1つ以上(時短分数・価格帯・容量)
- 「正直、こういう人は要らない」の節 ← **これがこのブログの核**
- 比較表(スキャンされやすく、滞在時間が伸びる)
- 関連記事への内部リンク1〜2本
- ハブ記事「買わなくていいものリスト」へのリンク

# 2. SEO

## 狙うキーワードの決め方

**ビッグワードは狙わない。** 2026年は大手以外がビッグKWで上位を維持するのが年々難しくなっている。
新規サイトが確実に流入を伸ばす手段は**ロングテール一択**。

- ロングテール = **3語以上の複合ワード**、月間検索ボリューム1000未満が目安
- **記事ごとに主要キーワードを1つだけ割り当てる**(複数狙うとどれも取れない)

| 狙わない(ビッグ) | 狙う(ロングテール) |
|---|---|
| 加湿器 おすすめ | 加湿器 一人暮らし 置き場所 |
| 掃除機 比較 | スティック掃除機 出しっぱなし 収納 |
| ドラム式 | ドラム式 洗濯機 搬入経路 測り方 |

## ショウさんの勝ち筋

大手が書かない**具体的な悩み**で差をつける。

- 「一人暮らし」「置き場所」「音」「搬入経路」「週何回使うか」
- 「◯◯ 要らない」「◯◯ 買わなくていい」← **競合がほぼいない金脈**
- 大手メディアは広告主の手前「買うな」と書けない。ここが構造的な差になる

## 記事タイトルの型

```
{主要キーワード}|{読者が得る結論}
```
例: 「急速充電器の選び方|失敗しない3つのチェックポイント」

- 主要キーワードは**タイトルの前半**に置く
- 32文字前後(検索結果で切れない長さ)
- 数字を入れる(「3つの」)

# 3. SNS運用(頻度と方針)

## ⚠ 頻度の方針を修正しました

以前「Xは1日1〜2本」としていましたが、**2026年のアルゴリズムでは
質を落として毎日投稿するより、週3〜5本の高品質投稿のほうが評価が高い**とされています。
アルゴリズムが最重視するのは **初速の反応** と **滞在時間・ブックマーク数** です。

薄い投稿を毎日出すと、低エンゲージメントの履歴が積み上がって逆効果になります。

## 推奨頻度(改訂版)

| チャネル | 頻度 | 1回あたりの狙い |
|---|---|---|
| **X** | **週3〜5本** | ブックマークされる情報密度。連投しない |
| **Threads** | 1日1〜2本 + 返信 | 会話が主目的なので頻度を落とさない |
| **Instagram** | 週2〜3本 | 保存される作り。カルーセル中心 |
| **ブログ** | 週2〜3本 | 記事30本まではここが最優先 |

**合計の作業時間は1日15〜20分**が目安。

## 投稿時間帯

朝6:00〜7:30(通勤)がいちばん強い。次に12:00(昼)、18:00(帰宅)。
家事層を狙うなら**朝**と**21時以降**も効く。

## Xで伸ばすための具体策

1. **ブックマークされる投稿を作る**
   - 「あとで見返したい」情報にする = 選び方3ポイント、比較表、チェックリスト
   - 感想や近況だけの投稿はブックマークされない → 頻度に含めない
2. **初速が命**
   - 投稿後30分の反応で伸びが決まる。反応が付きやすい時間に出す
   - 投稿直後に自分でリプライを付けて補足すると滞在時間が伸びる
3. **リプライと引用リポストが新規認知の主力**
   - フォロワー0の初期は、自分の投稿より他人への丁寧なリプライのほうが露出する
   - 影響力のある人の投稿に自分の言葉を添えて引用すると、相手に通知が届く
4. **連投しない**
   - 1日に何本も出すと、それぞれの初速が分散して全部が伸びない

## 投稿の質のチェックリスト

出す前に自問する。1つでもNoなら出さない(頻度より質を優先)。

- [ ] これは「あとで見返したい」情報か?
- [ ] 数字が1つ以上入っているか?
- [ ] 誰かの役に立つか?(感想だけになっていないか)
- [ ] ショウさんの口調になっているか?(俺・若者言葉1〜2個)
- [ ] 他の投稿と文面がかぶっていないか?
