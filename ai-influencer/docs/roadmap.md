# ゼロからの立ち上げロードマップ

方針: **最初は広告を打たない。まず信頼を積む。**
config.yaml の `phase: trust` が信頼構築期、`phase: monetize` が収益化期。

## フェーズ1: 信頼構築期(最初の1〜2ヶ月)← いまここ

**アフィリエイトリンクを一切貼らない。** 役立つ情報だけを出し続けてフォロワーを作る期間。
リンクを貼らないのでPR表記も不要。

### Week 1: 開設
- [x] A8.net登録(完了)
- [x] ブログ「暮らしのショートカット」をCloudflare Pagesで公開
- [ ] X・Instagram・Threadsアカウント開設(プロフィール文は docs/persona.md の各SNS別の文面を使用)
- [ ] 楽天ROOM開設(ただしフェーズ1では本格運用しない。棚づくりだけ)
- [ ] アイコン画像を3チャネルで統一

### Week 1〜8: とにかく投稿を重ねる
毎日の目安(1日15分):
- **X**: 1〜2投稿。選び方のコツ、「これは要らん」話、一人暮らしの小ネタ
- **Instagram**: 1投稿。画像+キャプション
- **Threads**: 1〜2投稿。Xより砕けた独り言。返信も拾う
- **ブログ**: 週2〜3本。「◯◯の選び方」系の記事(広告リンクなし)

キューは毎朝GitHub Actionsが生成する(`phase: trust` なのでリンクなしの文面が出る)。

### フェーズ1の目標
- ブログ記事20本以上
- 各SNSでフォロワーが少しずつ増え、反応の取れるテーマが見えている
- 「この人の“要らん”は信用できる」と思われる状態

## フェーズ2: 収益化期(信頼が付いてから)

切り替え方: `config.yaml` の `phase: trust` を `phase: monetize` に変更するだけ。
以後、生成される文面に商品リンクとPR表記が入る。

- [ ] 楽天ROOMを本格運用(キューの紹介文を毎日2〜3件コピペ投稿+いいね回り)
- [ ] ブログ記事にアフィリエイトリンクを追加
- [ ] A8の広告主に提携申請(記事が20本あれば通りやすい)
  - 狙い目: 家電物販、格安SIM、モバイルWiFi、家事代行、宅配食材
- [ ] フェーズ1で反応が良かったテーマから優先的に商品を紹介

**注意**: リンクを貼る投稿には必ずPR表記を入れる(ステマ規制)。システム側でも自動付与される。

## フェーズ3: 拡張

- [ ] **TikTok**: 短尺動画で新規流入(解説・比較・あるある型。実機レビューはAIなのでやらない)
- [ ] **Pinterest**: 画像検索経由の長期集客。ピンは資産として残る
- [ ] セルフバックで初期資金を作る(A8のクレカ発行・口座開設など)
- [ ] アプリ(PWA)化を検討
