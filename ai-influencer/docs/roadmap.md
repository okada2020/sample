# ゼロからの立ち上げロードマップ

フォロワー0・実績0からの手順。方針は「楽天とA8を最初から並行」。

## Week 1: アカウント開設と資金づくり

- [ ] 楽天ROOM開設(ジャンル: 時短家電・便利グッズ・日用品に特化)
- [ ] 楽天アフィリエイトID確認 / [Rakuten Developers](https://webservice.rakuten.co.jp/)でアプリID発行
- [ ] [A8.net](https://www.a8.net/)登録(ブログ未完成でも登録可)
- [ ] [もしもアフィリエイト](https://af.moshimo.com/)登録
- [ ] **セルフバックで初期資金を作る**(クレカ発行・口座開設などで1〜5万円。成果条件・否認条件を必ず確認)
- [ ] X・Instagramアカウント開設(プロフィールは docs/persona.md の文面を使用)

## Week 1-2: 発信の土台

- [ ] 楽天ROOMに投稿を10〜20件入れてから「いいね回り」を開始(先に棚を作る)
- [ ] ブログ「暮らしのショートカット」をCloudflare Pagesで公開(site/ ディレクトリ)
- [ ] 記事が3〜5本たまったらA8の広告主に提携申請
  - 狙い目: 家電物販、格安SIM、モバイルWiFi、家事代行、宅配食材(「固定費・家事の引き算」文脈で自然に書ける)

## Week 2〜: 毎日の運用(1日10〜15分)

1. パイプラインが毎朝キューを生成(GitHub Actions)
2. 楽天ROOM: キューの紹介文で2〜3件投稿+いいね回り15分
3. X: 自動投稿(または手動でコピペ)
4. Instagram: キャプションを使って1件投稿
5. ブログ: 週2〜3本、生成ドラフトを確認・修正して公開

## Month 2〜: 伸ばす

- [ ] Pinterestビジネスアカウント開設 → ブログ/ROOMへの誘導ピンを量産(画像は長期資産になる)
- [ ] 楽天お買い物マラソン・スーパーセール時に投稿を増量
- [ ] ASP成果レポートを見て、売れたジャンルへ config.yaml のキーワードを寄せる
- [ ] A8高単価記事(格安SIM比較など)をブログの検索流入が付いたページから内部リンク

## Month 3〜: アプリ(後発)

ファンが付いてから検討。ブログのブックマーク的なPWA(お得情報通知)から小さく始める。
