# チャネル別 運用戦略

「AIのショウさん」を伸ばすための、各チャネルの役割・投稿方針・伸ばし方。
前提として**いまはフェーズ1(信頼構築期)。広告リンクは貼らない。**

**記事の書き方・SEO・投稿の質の基準は [writing-seo.md](writing-seo.md) にまとめてあります。**

## 全体の考え方

```
Threads・Instagram  ──→  X  ──→  ブログ  ──→  (フェーズ2)楽天ROOM / A8
   認知・会話            拡散      検索流入・信頼        収益
                                      ↑
                                  AIアプリ(将来の自社資産)
```

**ブログが本体、SNSは入口。** SNSはアルゴリズム次第で消えるが、ブログとアプリは自分の資産として残る。
だからSNSでは必ずブログへ導線を張る。

**最大の武器は「これは要らん」と言えること。** 全チャネルで、
「買え」と同じ熱量で「買うな」を言う。これが他のアフィリエイト系アカウントとの最大の差になる。

## X — 役割: 拡散と発見

### 投稿方針
- **週3〜5投稿**(2026年のアルゴリズムでは、質を落とした毎日投稿より高評価)
- アルゴリズムが最重視するのは**初速の反応**と**滞在時間・ブックマーク数**
- 薄い投稿を毎日出すと低エンゲージメントの履歴が積み上がって逆効果
- **連投しない**。1日に何本も出すと初速が分散して全部伸びない
- 伸びる型の優先順位:
  1. **「これ買うな」型** … 逆張りは最も止まりやすい
  2. **「ここだけ見ればいい」型** … 3ポイントに絞った選び方
  3. **失敗談型** … 「サイズ測らずに買って詰んだ」
  4. **アプリ開発の進捗** … 非エンジニアが手探りで作る話
- リンクは**貼らない**(フェーズ1)。リンクを貼ると表示が伸びにくいという傾向もあるので、
  フェーズ1は純粋にテキストで価値を出すことに集中する

### 伸ばし方
- 初投稿は**必ずピン留め**。プロフィール流入の受け皿になる
- 投稿時間は**朝7〜8時**(通勤)と**夜21〜23時**(帰宅後)が家事層に届きやすい
- 同ジャンル(時短家電・一人暮らし・ガジェット)の投稿に**丁寧なリプライ**を送る。
  フォロワー0の初期は、これが唯一の露出手段
- 伸びた投稿は必ず記録して、同じ型を再利用する

### 3ヶ月後の目安
フォロワー500〜1,000。数より「反応が取れるテーマが分かっている」ことが重要。

## Instagram — 役割: 世界観と保存

### 投稿方針
- **週3〜4投稿**。Xより低頻度でいいので、1枚目の画像に手をかける
- **カルーセル(複数枚)中心**。1枚目で問題提起 → 2〜4枚目で解説 → 最後にまとめ
  - 例: 1枚目「充電器、W数だけ見てない?」→ 2〜4枚目で3ポイント → 5枚目まとめ
- 狙う指標は**いいねより「保存」**。「あとで見返したい」情報設計にする
  → チェックリスト形式・比較表形式が強い

### 伸ばし方
- 2025年以降、Instagramは**オリジナルコンテンツを優遇**する方向。他所の使い回しをしない
- リールも試す。ただしAIキャラなので実機を持つ演出はしない。
  **文字とナレーション中心の解説リール**にする
- ハイライトに「選び方まとめ」「これは要らん」を作って、プロフィール訪問者の回遊を作る

### 3ヶ月後の目安
フォロワー300〜800。保存率が高い投稿の型を2〜3個見つける。

---

## Threads — 役割: 会話と人格

### 投稿方針
- **1日1〜2投稿**。ここは3チャネルで**いちばん雑に、人間くさく**
- 商品の話をしない日があっていい。家事の愚痴、段取りの話、アプリ開発の詰まりどころ
- **質問で終える投稿**を週に2〜3回混ぜる(「みんなが家事でいちばんだるい工程は?」)

### 伸ばし方
- Threadsは**返信が最大のリーチ源**。他人の投稿に返信するほうが、自分の投稿より伸びる
- 自分の投稿に付いた返信には**全部返す**(初期は特に)
- Instagramと連携しているので、Threadsで興味を持った人がInstagramに流れる導線がある

### 3ヶ月後の目安
フォロワー300〜600。「返信が来るアカウント」になっていること。

## ブログ「暮らしのショートカット」 — 役割: 収益の本体

### 投稿方針
- **週2〜3本**。3ヶ月で20〜30本が目標(A8の提携審査もこのくらいあると通りやすい)
- 記事の型を3つに固定して量産する:
  1. **「◯◯の選び方」**(検索流入の主力。例:「加湿器の選び方」)
  2. **「◯◯は買わなくていい人」**(競合が少なく、信頼が付く)
  3. **「一人暮らしの家事の段取り」**(商品を出さない読み物。回遊とファン化に効く)
- 各記事の末尾から、関連記事へ**内部リンク**を必ず1〜2本張る

### SEOの考え方
- 狙うのは「加湿器 選び方」のような**ミドルキーワード**。
  「加湿器 おすすめ」のような激戦区は最初から狙わない
- 「一人暮らし」「置き場所」「音」など、**大手が書かない具体的な悩み**で差をつける
- AIが書いた記事だからこそ、**開示と正直さ**で信頼を担保する(体験談は書かない、要らんも書く)

### 3ヶ月後の目安
記事30本、検索流入が発生し始めている状態。ここでフェーズ2に切り替える。

## AIアプリ — 役割: 将来の自社資産 + いまのコンテンツ

**アプリは完成前から価値がある。** 開発過程そのものがコンテンツになる。

- 「非エンジニアの事務職がAIでアプリを作る」は現在いちばん共感を集めやすいテーマの一つ
- 詰まったところ、失敗、諦めた機能を出す。うまくいった話より伸びる
- 完成したら、ブログとSNSからそのまま配布できる。**アフィリエイトと違い手数料も規約リスクもない**
- 中身が決まったら、アプリの想定ユーザーに合わせて発信テーマを寄せていく

---

## 楽天ROOM / A8 — フェーズ2から本格稼働

いまは棚を作るだけ。信頼が付く前に売りにいくと、いちばん大事な信用を先に失う。

- **楽天ROOM**: フェーズ2で毎日2〜3件投稿+いいね回り。低単価×高回転
- **A8**: 記事が20本を超えたら提携申請。格安SIM・モバイルWiFiなどの高単価案件を
  「固定費の段取りを見直す」文脈で扱う。高単価×低頻度
- 切り替えは `config.yaml` の `phase: trust` → `monetize` だけ

## TikTok — フェーズ3

- AIキャラなので**実機レビューはしない**。解説・比較・あるある型で構成する
- 「これ買うな」型はTikTokでも最も止まりやすい
- 参入は、X・Instagram・Threadsの運用が回るようになってから

---

## いま一番大事なこと

**毎日投稿を止めないこと。** フォロワー0の期間は必ずあり、そこで止めると何も残らない。
1日15分でいいので、3チャネルに1本ずつ投げ続ける。
反応が取れるテーマは、続けているうちにデータで分かるようになる。
