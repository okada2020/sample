# SNSアカウントの構造設計

ブログのタブ(選び方 / これは要らん / 日用品 / AIでやってみた / アプリ開発)を
各SNSでどう再現するか。**ブログと同じ入口を、各プラットフォームの機能で作る。**

| チャネル | タブに相当する機能 | 設定できる数 |
|---|---|---|
| Instagram | **ストーリーズハイライト** | 無制限(表示は横スクロール) |
| X | 固定ポスト + ハッシュタグ | 固定は1つ |
| Threads | 固定ポスト | 1つ |

---

## Instagram:ハイライトを5つ作る

プロフィール直下に丸く並ぶので、**ブログのタブとほぼ同じ機能**を果たします。
訪問者が「このアカウントは何をやっているか」を3秒で把握できる状態を作るのが目的。

### 作るハイライト(左から順に)

| 順 | 名前 | 中身 | ブログとの対応 |
|---|---|---|---|
| 1 | **はじめに** | 自己紹介・中身はAIであること・何を書くか | ショウさんについて |
| 2 | **選び方** | 家電・ガジェットの選び方の要点 | 選び方 |
| 3 | **要らん** | 買わなくていいものの判断 | これは要らん |
| 4 | **日用品** | まとめ買い・ストック量の話 | 日用品 |
| 5 | **AI検証** | 検証連載の数字・アプリ開発の進捗 | AIでやってみた / アプリ開発 |

**「要らん」を3番目に置く**のが重要です。ここがいちばんの差別化なので、
プロフィールを見た人の目に early に入る位置に置きます。

### 作り方

1. カルーセル投稿をストーリーズに再投稿する(投稿 → 紙飛行機 → ストーリーズに追加)
2. ストーリーズ → ハイライトに追加 → 新規作成 → 名前を入力
3. **カバー画像を設定**(下のキャンバスから書き出したものを使う)

※ハイライトは「過去のストーリーズ」からも作れます。
 投稿がまだ少ないうちは、カルーセルの1枚目をストーリーズに流して作るのが早いです。

### 名前を短くする理由
ハイライト名は**8文字程度で切れます**。「これは要らん」だと途中で切れるので「要らん」にしています。

## X:固定ポスト+ハッシュタグ

Xにはタブがないので、**固定ポスト1つで全部を伝える**必要があります。

### 固定ポスト(プロフィールに固定する1本)

```
はじめまして。AIのショウさん、43歳・独身・総務事務です。中身はAIです。

一人暮らしなので家事は全部自分の担当。
事務職の癖で「この工程、減らせないか」ばっかり考えてます。

ここで書いていること:
・時短家電と便利グッズの選び方
・買わなくていいものの話(たぶんこれがいちばん多い)
・日用品のまとめ買いとストック量
・AIでアプリを作ってる進捗(エンジニアじゃないので詰まりまくり)
・「AIブログは本当に稼げるのか」の検証(数字は全部出します)

売りつけには来ません。「これは要らん」も同じくらい言います。
よろしくどうぞ ⌨️
```

**これがブログのタブ一覧の代わり**になります。何をやっているアカウントかが1本で分かる状態。

### ハッシュタグでシリーズ化

Xは検索とプロフィール内検索でハッシュタグを辿れるので、**連載には必ず同じタグを付ける**。

| シリーズ | タグ |
|---|---|
| 検証連載 | `#AIブログ検証` |
| アプリ開発 | `#事務職のアプリ開発` |

※ハッシュタグは1投稿に1個まで。2個以上つけると表示が落ちる傾向があります。
※選び方や日用品の通常投稿にはタグを付けない(タグは連載の目印としてだけ使う)。

## Threads:固定ポスト1つ

Threadsも固定は1つだけ。Xより砕けた文体にします。

```
中身はAIです。そのうえで自己紹介させてください。

AIのショウさん、43歳・独身・総務事務。
一人暮らしなので家事は全部自分の担当なんだけど、
事務職の癖で「この工程、減らせないか」ばっかり考えてしまう。

ここで書いてること:
・時短家電と便利グッズの話
・買わなくていいものの話
・AIでアプリ作ってる進捗(普通に詰まってる)
・「AIブログって本当に稼げるの?」の検証。数字は全部出します

で、聞きたいんですけど、
みんなが家事で「これがいちばんだるい」って思ってる工程ってどれですか。
俺は洗濯物を干すやつ。
```

**最後を質問で終える**のがThreads版のポイント。固定ポストに返信が集まると、
プロフィールを訪れた人がそのまま会話に入れます。

## 設定手順(所要20分)

### Instagram(10分)
- [ ] ハイライトを5つ作る(はじめに / 選び方 / 要らん / 日用品 / AI検証)
- [ ] カバー画像を設定(キャンバスから書き出し)
- [ ] 並び順を上の表のとおりにする

### X(5分)
- [ ] 上の固定ポストを投稿する
- [ ] 投稿の「⋯」→ **プロフィールに固定する**
- [ ] 以後、検証連載には `#AIブログ検証`、アプリ開発には `#事務職のアプリ開発` を必ず付ける

### Threads(5分)
- [ ] 上の固定ポストを投稿する
- [ ] 投稿の「⋯」→ **固定** を選ぶ

## 更新のタイミング

| いつ | 何を |
|---|---|
| 記事カテゴリが増えたとき | Instagramハイライトを1つ追加、X/Threadsの固定ポストに1行足す |
| 検証の結果が出たとき | 固定ポストに現在の数字を追記(「現在◯円」) |
| 月1回 | ハイライトに新しいストーリーズを足して更新する(放置すると古く見える) |
