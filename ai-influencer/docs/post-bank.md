# 投稿ストック(2週間分)

コピペして投稿するだけ。**考える時間をゼロにするためのファイル。**
使ったら行頭に `[済]` を付ける。残りが5本を切ったら補充する。

- 信頼構築期のため**リンクなし・PR表記なし**
- Xは1日1〜2本、Threadsは1日1〜2本、Instagramは週2〜3本が目安
- 同じ日に同じネタをX/Threads両方に出さない(文面を変えても重複感が出る)

# X(12本 / 約3〜4週間分)

**週3〜5本ペース。連投しない。** 狙うのはブックマーク。
「あとで見返したい」と思われる密度がある投稿だけを並べてある。
投稿時間は朝6:00〜7:30、または21時以降が家事層に届きやすい。

## X-01 選び方(ブックマーク狙い)
```
充電器を選ぶとき、見るのは3つだけでいい。

・出力は20W以上
・規格はUSB PD対応
・ポート数は「同時に何台挿すか」から逆算

スペック表の細かい数字は正直見なくていい。
あとケーブルが古いままだと速度出ないので、そこもセットで。
```

## X-02 要らん型(逆張り。いちばん止まる)
```
ロボット掃除機、部屋の広さで選ぶと失敗します。

決まるのは「床に物があるかどうか」。

床が散らかる人が買うと、走らせる前に片づける工程が増える。
手間を減らすために買ったのに、手間が1個増えてる。

これがいちばん多い失敗です。
```

## X-03 チェックリスト(保存される型)
```
家電を買う前に測る3ヶ所。

① 置き場所の内寸(外枠じゃなく内側)
② 搬入経路(玄関・廊下・曲がり角)
③ ドアの開閉スペース

目安は本体幅+10cm。
置けるサイズでも、家の中を通らなければ意味がない。

レビュー30分読むより、メジャー5分のほうが効きます。
```

## X-04 判断基準(短くて強い)
```
便利グッズを買う前の質問はひとつだけ。

「これ、週に何回使う?」

週1未満なら買わない。
1回3分の手間を1分に減らす道具でも、月1回なら年24分しか減らない。
収納は365日占有されるので、差し引きでマイナスです。
```

## X-05 比較(数字が入る)
```
乾燥機、方式で価格がここまで違う。

ヒーター式 … 3〜8万円 / 電気代は高め
ヒートポンプ式 … 12〜25万円 / 電気代は安い

毎日回すならヒートポンプ。
週2〜3回なら初期費用の差を電気代で取り返しにくい。
使用頻度から逆算するのが正解です。
```

## X-06 落とし穴(共感+実用)
```
乾燥機を買うとき、商品名の「11kg」に釣られないでほしい。

あれは洗濯容量。乾燥容量は6kgだったりする。

乾燥まで一気にやりたいなら見るのは後者です。
一人暮らしなら乾燥3〜5kgあれば足りる。
```

## X-07 段取り型(商品を出さない)
```
一人暮らしの家事、工程を全部書き出して時間を数えたことがある。

いちばん食ってたのは「干す」だった。

洗うのは機械がやる。畳むのは座ってできる。
干すだけ立ちっぱなしで10〜15分持ってかれる。しかも雨だと詰む。

ここは道具で丸ごと消せる工程です。
```

## X-08 代替案(安いほうを勧める)
```
掃除しない理由の大半って「掃除機を出すのがめんどくさい」だと思うんですよ。

なら出す工程を消せばいい。

壁掛けスタンド2,000〜4,000円で出しっぱなしにできる。
ロボット掃除機の1/20の予算で、掃除の頻度は普通に上がります。
```

## X-09 機能の要否(判断を助ける)
```
電気ケトルの温度調整機能、要る人と要らない人がはっきり分かれる。

要る … 緑茶(70〜80℃)かドリップコーヒー(90℃前後)を毎日淹れる人
要らない … カップ麺とインスタントが主戦場の人

後者なら100℃一択なので、1,500〜3,000円上乗せする意味はほぼない。
```

## X-10 サイズ選び(一人暮らし特化)
```
一人暮らしの家電、大は小を兼ねません。

容量が大きい = 本体も大きい = 置き場所を食う。

ワンルームは置き場所がいちばんの制約なので、
「ちょうどいいサイズ」を選ぶほうが満足度が高い。

電気ケトルなら0.8L前後、乾燥容量なら3〜5kgが目安です。
```

## X-11 スタンス表明(固定ファンが付く)
```
このアカウントで一個だけ決めてることがあって。

「買え」と同じ熱量で「買わなくていい」も言う、ってやつ。

紹介する側が要らんものを要らんと言わなくなった時点で、
読む価値がなくなるので。そこだけは守ります。
```

## X-12 メタ視点(共感で伸びる)
```
「時短家電」って言葉、あんまり好きじゃないんですよね。

時間が短くなるかどうかじゃなくて、
その工程が"消える"かどうかが大事だと思ってて。

5分が3分になるより、5分が0分になるほうが圧倒的に効く。
道具を選ぶときの基準は、たぶんこっちです。
```

## 補足: 投稿直後にやること

投稿後30分の反応で伸びが決まる。**投稿したら自分でリプライを1本足す。**
補足・実例・「ちなみに」の一言でいい。滞在時間が伸びて初速が上がる。

例(X-01に対して):
```
ちなみに30W以上を選ぶと、スマホ・タブレット・ノートPCを1台でまかなえます。
充電器を1個に減らすと、机の上のケーブル類が一気に減るのでおすすめ。
```

# Instagram(5本 / 2週間分)

カルーセル前提。テンプレートは[カルーセルテンプレート]のアートボードを流用する。

## 1. 急速充電器の選び方(テンプレート実装済み)
6枚構成。フック→3ポイント→要らん→まとめ。

## 2. 衣類乾燥機の選び方
```
1枚目: 干す時間、まだ払ってますか?
2枚目: ヒートポンプ or ヒーター(表)
3枚目: 見るのは「乾燥容量」。洗濯容量に釣られない
4枚目: 置き場所と搬入経路を先に測る
5枚目(黒地): 部屋干しで困ってない人は要りません
6枚目: まとめ + 保存誘導
```
キャプション冒頭:「洗って干して畳む。この真ん中、丸ごと消せます。」

## 3. ロボット掃除機、要る?要らない?
```
1枚目: ロボット掃除機、広さで選ぶと失敗します
2枚目: 決まるのは「床に物があるか」
3枚目: 効かない人の条件(4つ)
4枚目: 効く人の条件(4つ)
5枚目(黒地): ワンルームなら壁掛けスタンドのほうが効くことも
6枚目: まとめ + 保存誘導
```
キャプション冒頭:「今日は買う話じゃなくて、買わない話をします。」

## 4. 電気ケトルの選び方
```
1枚目: 3,000円で、朝が少し変わります
2枚目: 容量は「一度に沸かす量」から(表)
3枚目: 内側の材質3種の違い
4枚目: 注ぎ口は細口か広口か
5枚目(黒地): 温度調整が要るのは緑茶とドリップの人だけ
6枚目: まとめ + 保存誘導
```

## 5. 買う前に測る3つの寸法
```
1枚目: 家電を買う前にやることは、レビューを読むことじゃない
2枚目: メジャーを出すことです
3枚目: ①置き場所の内寸
4枚目: ②搬入経路(玄関・廊下・曲がり角)
5枚目: ③ドアの開閉スペース
6枚目(黒地): 置けるサイズでも、通らなければ意味がない
```
キャプション冒頭:「搬入経路で詰むパターン、地味に多いです。」

# 検証連載(Threads用)

## 検証スタート
```
検証を始めます。

AIキャラのアフィリエイトブログって本当に稼げるのか、
0円・フォロワー0から3ヶ月やってみます。

「AIで月◯万円」みたいな話をよく見るんですが、
実際に数字を出してる人ってほとんど見ないんですよね。

なので自分でやります。収益は1円単位で出します。

ルールは1個だけ決めてて、ダメだったらダメと書く。
たぶん3ヶ月で1万円は届かないと思ってるんですが、
届かなかったらそう書きます。そのほうが役に立つので。
```

## 途中経過(数字が伸びないとき用)
```
検証◯週目、正直あんまり伸びてないです。

フォロワー◯人、PV◯、収益◯円。

こういうときに書きたくなくなるんですけど、
悪い数字を出さない検証は検証じゃないので出します。

伸びない理由、たぶん◯◯だと思ってて。来週そこ変えます。
```
