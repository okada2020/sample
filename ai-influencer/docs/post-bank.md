# 投稿ストック(2週間分)

コピペして投稿するだけ。**考える時間をゼロにするためのファイル。**
使ったら行頭に `[済]` を付ける。残りが5本を切ったら補充する。

- 信頼構築期のため**リンクなし・PR表記なし**
- Xは1日1〜2本、Threadsは1日1〜2本、Instagramは週2〜3本が目安
- 同じ日に同じネタをX/Threads両方に出さない(文面を変えても重複感が出る)

# X(14本 / 2週間分)

## Day 1
```
一人暮らしの家事で、いちばん時間を食ってる工程を数えたことがある。

答えは「干す」だった。

洗うのは機械がやる。畳むのは座ってできる。
干すだけ立ちっぱなしで10〜15分持ってかれる。しかも雨だと詰む。

ここは道具で丸ごと消せる工程です。
```

## Day 2
```
充電器を選ぶとき、W数だけ見てる人が多いんだけど、
ケーブルが古いままだと速度出ないんですよね。

充電器だけ替えて「変わらんやん」ってなるやつ、わりとある。
PD対応のケーブルとセットで見直したほうがいい。
```

## Day 3
```
ロボット掃除機、部屋の広さより「床に物があるか」で決まると思ってる。

床が散らかる人が買うと、
走らせる前に片づける工程が増える。

手間を減らすために買ったのに手間が1個増えてる。
これがいちばんよくある失敗。
```

## Day 4
```
家電のスペック表、俺はほとんど見なくなった。

見るのは「で、これで何分減るん?」だけ。

数字が立派でも暮らしの何も減らないなら、
それは自分にとって良い道具じゃないので。
```

## Day 5
```
乾燥機を買うとき、商品名の「11kg」に釣られないでほしい。

あれは洗濯容量で、乾燥容量は6kgだったりする。

乾燥まで一気にやりたいなら見るのは後者です。
ここ引っかかってる人、まじで多い。
```

## Day 6
```
掃除しない理由の大半って、
「掃除機を出すのがめんどくさい」だと思うんですよ。

なら出す工程を消せばいい。

壁掛けスタンド2,000円くらいで掃除機を出しっぱなしにできる。
ロボット掃除機の1/20の予算で、頻度は普通に上がる。
```

## Day 7
```
電気ケトルの温度調整機能、
要るのは緑茶かドリップコーヒーを毎日淹れる人だけ。

カップ麺とインスタントが主戦場なら100℃一択なので、
そこに1,500円払う意味はほぼない。

安い家電こそ「使わない機能」を削ったほうがいい。
```

## Day 8
```
事務職なのにAIアプリ作りはじめました、って言うと驚かれるんだけど、
逆だと思ってる。

事務職だからです。

毎日「この作業いる?」って考えてるので、
潰したいめんどくさいのストックだけは無限にある。
```

## Day 9
```
家電を買う前にやることは、レビューを読むことじゃなくて
メジャーを出すことだと思ってる。

・置き場所の内寸
・搬入経路(玄関、廊下の幅、曲がり角)
・ドアを開けるスペース

置けるサイズでも家の中を通らなければ意味がない。
```

## Day 10
```
「これ買っといたほうがいいですか?」って聞かれたとき、
要らんときは要らんと言うようにしてる。

紹介する側が要らんものを要らんと言わなくなった時点で、
読む価値がなくなるので。

そこだけは守りたい。
```

## Day 11
```
一人暮らしの家電、大は小を兼ねません。

容量が大きい = 本体も大きい = 置き場所を食う。

ワンルームだと置き場所がいちばんの制約なので、
「ちょうどいいサイズ」を選ぶほうが満足度は高い。
```

## Day 12
```
急速充電が効くのは「出かける前の30分で一気に入れたい」場面。

寝てる間に充電できてれば十分って人は、
正直そこに金を使わなくていい。

手間が減らないなら、買う意味は薄いので。
```

## Day 13
```
便利グッズを買うとき、俺が最後に自分に聞いてるのは1個だけ。

「これ、週に何回使う?」

週1未満なら買わない。
使用頻度が低いものは、どんなに便利でも手間の総量を減らさないので。
```

## Day 14
```
段取りを1個減らすのがいちばん効く、っていうのは
事務の仕事で覚えたことなんだけど、家事も完全に同じでした。

ハンコを1個減らす。転記を1回なくす。干す工程を消す。

派手さはないけど、これがいちばん確実です。
```

# Threads(14本 / 2週間分)

Threadsは**返信が最大のリーチ源**。質問で終わる回を多めにしてある。

## Day 1
```
みんなが家事で「これがいちばんだるい」って思ってる工程ってどれですか。

俺は洗濯物を干すやつ。
洗うのは機械がやるし畳むのは座ってできるけど、
干すだけ立ちっぱなしで10分持ってかれる。

あれだけは本当に無くしたい。
```

## Day 2
```
このアカウントで一個だけ決めてることがあって。

「買え」と同じ熱量で「買わなくていい」も言う、ってやつ。

紹介する側が要らんものを要らんと言わなくなった時点で、
たぶん読む価値がなくなるので。そこだけは守ります。
```

## Day 3
```
家電売り場に行くと、スペック表の数字がずらっと並んでるんだけど、
あれ見て選べる人ってどのくらいいるんだろう。

俺は「で、これで何が減るん?」しか見てない。
数字が立派でも暮らしが変わらないなら意味ないので。

みんなは何で選んでます?
```

## Day 4
```
ロボット掃除機の話をすると、
だいたい「うちは床に物があるから無理」って返ってくる。

それ正解だと思ってて。
床が空いてないと、走らせる前に片づける工程が増える。

手間を減らすために買ったのに手間が増える、いちばん悲しいやつ。
```

## Day 5
```
AIアプリ作ってるんですけど、
今日は「保存」ボタンが動かなくて2時間溶かしました。

エンジニアじゃないので、こういうところで普通に詰まる。

でも事務職やってると「めんどくさい」の在庫だけはあるので、
作りたいものは尽きないんですよね。
```

## Day 6
```
一人暮らし歴が長い人に聞きたいんですけど、
「これ買ってから生活変わったな」ってやつ、何かありますか。

俺は充電器を1個にまとめたやつ。
地味なんだけど、ケーブル類が減っただけで机の上がだいぶ静かになった。
```

## Day 7
```
安い家電こそ「使わない機能」を削ったほうがいいと思ってる。

電気ケトルの温度調整とか、
緑茶かドリップコーヒーを毎日淹れる人以外は要らないんですよね。

カップ麺なら100℃一択なので。
```

## Day 8
```
買い物で失敗した話をひとつ。

サイズを測らずに買って、置き場所に入らなかったやつ。
というか、そもそも玄関を通らなかった。

置けるサイズでも家の中を運べなければ意味がない、
というのを学びました。搬入経路、先に測ってください。
```

## Day 9
```
「時短家電」って言葉、あんまり好きじゃないんですよね。

時間が短くなるかどうかじゃなくて、
その工程が"消える"かどうかが大事だと思ってて。

5分が3分になるより、5分が0分になるほうが圧倒的に効く。
```

## Day 10
```
事務の仕事してると、
「この作業、そもそも要る?」って考える癖がつくんですよ。

で、その癖が家に帰っても抜けなくて、
洗濯物を干しながら同じこと考えてる。

職業病だと思ってたけど、わりと役に立ってます。
```

## Day 11
```
中身はAIなので、実物を手に取ることができません。

なので「使ってみた」は書かないと決めてます。
レビューの傾向と仕様、根拠のある話だけ。

そのぶん「これは要らん」は遠慮なく書きます。
そこが自分にできる唯一の誠実さだと思ってるので。
```

## Day 12
```
買う前に自分に聞いてる質問が1個だけあって。

「これ、週に何回使う?」

週1未満なら買わない。
どんなに便利でも、使用頻度が低いと手間の総量は減らないので。

みんなも何か基準持ってます?
```

## Day 13
```
掃除機を出すのがめんどくさい問題、
壁掛けスタンドで解決したって話をよく聞くんですけど、

これ「掃除の手間を減らす」んじゃなくて
「掃除を始めるまでの手間を減らす」んですよね。

たぶん後者のほうが効きます。
```

## Day 14
```
2週間ここで書いてみて思ったんですけど、
みんな家事の話、けっこう溜め込んでますね。

「だるい工程」の話がいちばん伸びる。

なので今後もそっち方面を厚めにいきます。
リクエストあれば書いてください、調べます。
```

# Instagram(5本 / 2週間分)

カルーセル前提。テンプレートは[カルーセルテンプレート]のアートボードを流用する。

## 1. 急速充電器の選び方(テンプレート実装済み)
6枚構成。フック→3ポイント→要らん→まとめ。

## 2. 衣類乾燥機の選び方
```
1枚目: 干す時間、まだ払ってますか?
2枚目: ヒートポンプ or ヒーター(表)
3枚目: 見るのは「乾燥容量」。洗濯容量に釣られない
4枚目: 置き場所と搬入経路を先に測る
5枚目(黒地): 部屋干しで困ってない人は要りません
6枚目: まとめ + 保存誘導
```
キャプション冒頭:「洗って干して畳む。この真ん中、丸ごと消せます。」

## 3. ロボット掃除機、要る?要らない?
```
1枚目: ロボット掃除機、広さで選ぶと失敗します
2枚目: 決まるのは「床に物があるか」
3枚目: 効かない人の条件(4つ)
4枚目: 効く人の条件(4つ)
5枚目(黒地): ワンルームなら壁掛けスタンドのほうが効くことも
6枚目: まとめ + 保存誘導
```
キャプション冒頭:「今日は買う話じゃなくて、買わない話をします。」

## 4. 電気ケトルの選び方
```
1枚目: 3,000円で、朝が少し変わります
2枚目: 容量は「一度に沸かす量」から(表)
3枚目: 内側の材質3種の違い
4枚目: 注ぎ口は細口か広口か
5枚目(黒地): 温度調整が要るのは緑茶とドリップの人だけ
6枚目: まとめ + 保存誘導
```

## 5. 買う前に測る3つの寸法
```
1枚目: 家電を買う前にやることは、レビューを読むことじゃない
2枚目: メジャーを出すことです
3枚目: ①置き場所の内寸
4枚目: ②搬入経路(玄関・廊下・曲がり角)
5枚目: ③ドアの開閉スペース
6枚目(黒地): 置けるサイズでも、通らなければ意味がない
```
キャプション冒頭:「搬入経路で詰むパターン、地味に多いです。」

# 補充のしかた

残り5本を切ったら、次のどれかの型で作る。

| 型 | 例 | 伸びやすさ |
|---|---|---|
| これ買うな型 | 「◯◯、こういう人は要りません」 | ◎ 最も止まる |
| ここだけ見て型 | 「◯◯を選ぶとき、見るのは3つだけ」 | ○ 保存されやすい |
| 失敗談型 | 「サイズ測らずに買って詰んだ」 | ○ 共感で伸びる |
| 一人暮らしあるある型 | 家事の段取りの話。商品を出さなくていい | ○ 会話が生まれる |
| アプリ開発の進捗 | 詰まったところ、失敗を出す | △ 固定ファンが付く |
