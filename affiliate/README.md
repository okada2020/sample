# くらしコレ — A8.net アフィリエイトサイト雛形

A8.net の広告コードを貼るだけで公開できる、アフィリエイトサイトの雛形です。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | トップページ(ヒーロー、ランキングTOP3、記事一覧、広告枠) |
| `article1.html` | レビュー記事のテンプレート |
| `about.html` | 当サイトについて/広告掲載の明示/プライバシーポリシー/免責事項 |
| `css/style.css` | 共通スタイル(レスポンシブ対応) |

## A8.net の広告コードの貼り方

1. [A8.net](https://www.a8.net/) にログイン
2. 紹介したい広告主と提携(プログラム検索 → 提携申請)
3. 「プログラム管理」→「参加中プログラム」→「広告リンク作成」でコードをコピー
4. 各HTML内の `<!-- ▼ A8.net 広告スロット -->` とコメントされた箇所にある
   `<div class="ad-placeholder">…</div>` を、コピーした広告コードに**丸ごと差し替え**る

広告コードは `<a href="https://px.a8.net/...">...</a><img src="https://www17.a8.net/..." ...>` の形式です。**コードは一切書き換えずそのまま**貼り付けてください(書き換えると成果が計測されません)。

## 公開前にやること

- ランキング・記事内の「サービスA/B/C」を実際に紹介する商品名・内容に書き換える
- `about.html` の運営者情報・お問い合わせ先を記入する
- 各記事冒頭の「※本記事にはアフィリエイト広告が含まれています」の表記は消さない(景表法・ステマ規制対応)
- GitHub Pages などで公開し、公開URLを A8.net にサイト登録する
