# キャッスルガード 〜城を守れ!〜

タップで矢を放ち、押し寄せる敵から城を守るディフェンスゲームです。
スマホ・PC のブラウザでそのまま遊べます(追加インストール不要)。

## 遊び方

- 👆 画面をタップ(長押しで連射)して矢を放つ
- ⚔️ 敵を倒すとゴールドを獲得
- 🛠 ウェーブの合間にゴールドで強化
  - 攻撃力アップ / 連射速度アップ / 同時発射 / 弓兵を雇う / 城の修理 / 城壁の強化
- 🐲 5ウェーブごとにボスが出現
- 🏰 城のHPが0になるとゲームオーバー。ベスト記録は端末に保存されます

## 起動方法

`castle-defense/index.html` をブラウザで開くだけで動きます。

ローカルサーバーで開く場合:

```bash
cd castle-defense
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

GitHub Pages を有効にすれば、スマホからも
`https://<ユーザー名>.github.io/<リポジトリ名>/castle-defense/` で遊べます。

## 技術構成

- HTML5 Canvas + Vanilla JavaScript(依存ライブラリなし)
- レスポンシブ対応(縦画面スマホ向けデザイン)
- WebAudio による効果音
- localStorage にベスト記録を保存

## アプリ(ストア配信)化について

このゲームは Web 技術で作られているため、以下の方法でアプリ化できます。

1. **PWA 化**: manifest とサービスワーカーを追加し「ホーム画面に追加」で
   アプリのように起動(いちばん手軽)
2. **Capacitor / Cordova**: この HTML をそのままラップして
   App Store / Google Play に配信
3. **ネイティブ移植**: Unity や Swift などで作り直す(本格的な収益化向け)
