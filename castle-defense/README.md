# サムライガード 〜忍者襲来〜

侍アーチャーを左右にドラッグして操作し、自動連射の矢で
忍者・天狗・鬼・竜の大群から和の城を守るハイテンポなディフェンスゲームです。
スマホ・PC のブラウザでそのまま遊べます(追加インストール不要)。

キャラクターはすべてコード描画のオリジナルベクターアート。
背景には富士山・満月・桜吹雪、城は石垣+白漆喰の塀+天守閣の日本の城です。

## 遊び方

- 👆 左右にドラッグして侍を移動(矢は一番手前の敵へ自動連射)
- ⛩ 上から流れてくる鳥居ゲートをくぐると一時強化
  - 矢+1 / 攻撃UP / 連射UP / +40両 / 城回復 — 左右どちらをくぐるかで戦略が変わる!
- 🥷 敵を倒すと小判(両)を獲得。連続撃破でコンボボーナス
- ⚒️ ウェーブの合間に小判で恒久強化
  - 業物の鏃 / 早撃ちの技 / 扇の陣(同時発射) / 足軽弓兵を雇う / 城の普請 / 石垣の強化
- 🐉 5ウェーブごとにボスが出現
- 🏯 城のHPが0になると落城(ゲームオーバー)。ベスト記録は端末に保存されます

## 起動方法

`castle-defense/index.html` をブラウザで開くだけで動きます。

ローカルサーバーで開く場合:

```bash
cd castle-defense
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

GitHub Pages を有効にすれば、スマホからも
`https://<ユーザー名>.github.io/<リポジトリ名>/castle-defense/` で遊べます。

## 技術構成

- HTML5 Canvas + Vanilla JavaScript(依存ライブラリなし)
- レスポンシブ対応(縦画面スマホ向けデザイン)
- WebAudio による効果音
- localStorage にベスト記録を保存

## アプリ(ストア配信)化について

このゲームは Web 技術で作られているため、以下の方法でアプリ化できます。

1. **PWA 化**: manifest とサービスワーカーを追加し「ホーム画面に追加」で
   アプリのように起動(いちばん手軽)
2. **Capacitor / Cordova**: この HTML をそのままラップして
   App Store / Google Play に配信
3. **ネイティブ移植**: Unity や Swift などで作り直す(本格的な収益化向け)
