# 🍎 フルーツ・クラウドランナー（Fruit Crowd Runner）

> 坂道でフルーツを転がす。ゲートをくぐって仲間を増やす。サルを蹴散らす。
> そして坂の終わりには——クマが待っている。

`index.html` をブラウザで開くだけで遊べるプロトタイプです（ライブラリ不要 / スマホ対応）。

---

## 1. コンセプト

**「増やす快感」と「一瞬で失う恐怖」を、下り坂のスピード感に乗せた 1 プレイ 40 秒のカジュアルゲーム。**

- ジャンル：クラウドランナー（群れを増やして進む "Count Masters" 系）
- プレイ時間：1 ステージ 30〜60 秒。負けても即リトライ。
- 操作：**横方向のドラッグだけ**。片手で遊べる。
- 「クラウド」は **crowd（群れ）** と **cloud（空の雲）** のダブルミーニング。
  坂の上は青空と雲、転がるのはフルーツの群れ。

### なぜ成立するか
数字が `×3` に膨らむ瞬間の気持ちよさと、`÷2` を踏んだ瞬間の絶望は、
説明なしで 1 秒で伝わる。チュートリアルがいらないので SNS 動画・広告クリエイティブとの相性が良い。

---

## 2. 遊び方

| 操作 | 内容 |
|---|---|
| ドラッグ / ← → / A・D | 群れを左右に動かす |
| タップ連打 / スペース | ボス戦で反撃（ダメージ 1.8 倍） |

1. フルーツ **15 個** から下り坂をスタート。
2. **ゲート**を通ると数が増減する。左右どちらをくぐるか一瞬で選ぶ。
3. **サル**にぶつかると食べられる。**サルの壁**は数が足りないと全滅。
4. 坂の終わりで **クマ**が襲ってくる。フルーツの数＝攻撃力。連打で押し切れ。
5. クリアで次ステージへ。フルーツは毎ステージ 15 個にリセット、スコアは累積。

## 3. ゲーム要素の設計

### 🚪 ゲート（増減）
道が左右 2 枚に区切られ、それぞれに演算が書かれている。通過した側の演算が適用される。

| 当たり | はずれ |
|---|---|
| `×2` `×3` `+10` `+20` `+30` | `-15` `-30` `÷2` `÷3` |

- 62%：当たり × はずれ（判断ゲーム）
- 23%：当たり × 当たり（どちらが得かの計算ゲーム）
- 15%：はずれ × はずれ → **このときは `÷` のみ**を出す。
  `÷` は切り上げなので 0 にならず、「理不尽な即死」を作らない。

### 🐵 サル（敵）
道のどこかに群れて立っている。接触するとフルーツを **頭数 ×1.5 個**食べられる。
避けられるが、ゲートとの位置関係でわざと「おいしい側の手前に置く」と悩ましくなる。

### 🧱 サルの壁（関門）
道幅いっぱいにサルが並び、**必要数**が表示される。

- 所持数 > 必要数 → 必要数だけ失って突破
- 足りない → **全滅（ゲームオーバー）**

必要数は `12 + ステージ×8 + 0〜10`。壁の **30 手前には必ずゲートを配置**して、
「あそこで増やしておけば届く」と事前に計画できるようにしてある（理不尽さの排除）。

### 🍒 ボーナス
道に落ちている大きなフルーツ。拾うと `+8〜18`。寄り道の誘惑。

### 🐻 クマ（ボス）
ゴールで待ち伏せ。ここだけ操作が変わり、**連打のゴリ押し勝負**になる。

| | 数式 |
|---|---|
| こちらの攻撃 | `フルーツ数 × 0.85 /秒`（連打中は ×1.8） |
| クマの叩きつけ | `8 + ステージ×4` 個（約 1.2 秒おき、ステージが上がるほど速い） |
| じわ減り | `1.5 + ステージ` 個/秒 |
| クマ HP | `100 + ステージ×55` |

→ ステージ 1 なら **40 個以上**で安定して勝てる。逆に 20 個で挑むと確実に負ける。
道中の増やし方がそのまま勝敗になる、という因果がプレイヤーに見えるチューニング。

### 🎨 キャラクターの方向性
「**ファンシーなのに、よく見るとグロい**」。鷹の爪団のようなフラットで安っぽい線と、
ちいかわ的な「かわいいのに救いがない」空気を狙っている。

- **全員、安っぽい笑顔で固定**。口角だけを上げた横に広い笑いで、歯は不揃い・一本欠け。
- **目は笑っていない**。白目が大きく瞳は点、左右で視線が微妙にズレている。充血あり。
- サルもクマも**ほっぺにチーク、耳の内側はピンク、リボン付き**。かわいい記号は全部乗せる。
- そのうえで口元には**果汁のよごれ**と、口角からしたたる一筋（赤）。爪の先にも付いている。
- クマは**ぬいぐるみ**として作ってある。お腹に縫い目、片目は × に縫い留められ、首にはリボンと鈴。
- フルーツたちも同じ安っぽい笑顔。**食べられる瞬間だけ ×＿× になる**。

画像素材は一切使わず、すべて Canvas のパスで描いている（`drawMonkey` / `drawBear` / `drawFruit`）。
`cheapSmile()`／`deadEye()`／`juiceStain()` を共通パーツにしているので、
新キャラを足すときも同じ「顔の安っぽさ」を使い回せる。

### スコア
`残ったフルーツ ×10 + ステージ×200` を累積。ベストスコアは `localStorage` に保存。

## 4. 難易度カーブ

ステージが上がるごとに、

- 坂が長くなる（`520 + ステージ×60`）
- 走る速度が上がる（`20 + ステージ×1.5`）
- サルの数・壁の必要数・クマの攻撃力と HP が上がる

一方で開始フルーツは常に 15。**上手くなるほど遠くへ行ける**設計。

## 5. 技術メモ

- **依存ライブラリなし**。`index.html` + `game.js` の 2 ファイルのみ。
- Canvas 2D の **1 点透視による擬似 3D**。`scale = 焦点距離 / 奥行き` で投影し、
  奥ほど下に沈む項を足して「下り坂」を表現している（`project()`）。
- **画面比に応じてカメラ高さと消失点を自動調整**。縦長スマホでも横長 PC でも、
  群れが常に画面の約 7 割の高さに来る。
- キャラクターは画像を使わず **すべて Canvas のパスで描画**（フルーツ／サル／クマ／木）。
  読み込み 0 秒、どの端末でもフォント依存なし。
- 効果音は WebAudio のオシレータ生成。音源ファイル不要。
- `window.CrowdRunner`（`state` / `startStage` / `skipToBoss` / `setFruits`）を
  QA・自動テスト用に公開している。

### 動かし方
```bash
# そのまま index.html を開いてもよい
python3 -m http.server 8000
# → http://localhost:8000/crowd-runner/
```

## 7. AI 活用のポイント（このプロトタイプ自体の作り方）

このゲームは「坂道・ゲート・サル・クマ」という**一言のアイデアから対話だけで実装**している。

1. **アイデア → 仕様の言語化**：ジャンルの定石（Count Masters 系）に当てはめて、
   勝敗条件・演算の種類・理不尽さの排除ポイントを先に決める。
2. **アセットを描かずに済ませる**：キャラクターを画像でなく数式・パスで生成させると、
   素材集めなしで見た目が揃う。差し替えも 1 関数で済む。
3. **数値バランスを式で持つ**：`ステージ×係数` の形で持たせておくと、
   「もう少し難しく」を会話で即反映できる。
4. **ヘッドレスブラウザで自動プレイ＆スクリーンショット**を撮り、
   崩れ・エラー・詰み局面を検出してから調整する（実際に道の継ぎ目と即死ゲートをこれで発見）。
