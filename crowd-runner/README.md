# 🍎 フルーツ・クラウドランナー（Fruit Crowd Runner）

> 坂の上に立った人間が、銃を撃つように果物を転がし落とす。
> 果物はゲートを抜けるたびに増え、サルに通行料を取られ、坂の底のクマにぶつかる。
> 弾は 9 発。届いた数がそのままダメージ。

`index.html` をブラウザで開くだけで遊べます（ライブラリ不要 / スマホ対応）。

---

## 1. コンセプト

**「ねらって撃つ」と「転がしながら増やす」を合体させた、1 プレイ 1〜2 分のカジュアルゲーム。**

- 坂の上＝プレイヤー（人間のシルエット）。坂の底＝クマ（ボス）。
- 1 発ごとに **ねらう → 転がす → 増減する → 着弾** の短いサイクルが回る。
- ボウリングやシューティングと同じ「撃つ前の緊張」と「転がっている間のハラハラ」が両方ある。
- 数字が `×4` に膨らむ瞬間と、サルに全部取られる瞬間の落差で見せる。

---

## 2. 操作

| 状態 | 操作 | 内容 |
|---|---|---|
| ねらう | ドラッグ（左右） | 撃ち出す角度を決める。予測線が壁の跳ね返りまで表示される |
| ねらう | はなす / スペース | 転がす（残弾 −1） |
| 転がり中 | ドラッグ（左右） | 転がる向きを微調整。強くは曲がらない |
| 共通 | ← → / A D | 同上（キーボード） |

---

## 3. ゲームの流れ（状態遷移）

```
title ──start──▶ aim ──fire──▶ roll ──着弾/全滅──▶ hit ──┬─ クマ HP 0 ─▶ clear ─▶ 次ステージ
                  ▲                                      ├─ 残弾 0     ─▶ over
                  └──────────────── 次の一発 ◀───────────┘
```

- **aim**：カメラは坂の上。人間が次の果物を手に持って構えている。
- **roll**：カメラが転がる果物を追う。坂なので**転がるほど加速**（18 → 最大 40 /秒）。
- **hit**：着弾演出（0.7〜1.0 秒）。このあいだにコースを**組み替える**。
- 1 発あたり約 4〜5 秒。9 発でステージ 1 本。

---

## 4. コースの要素

コースは **1 本のレーン**（長さ `125 + ステージ×12`）。毎回同じレーンを撃つが、
**1 発撃つごとに中身が組み替わる**ので、同じ正解ルートの繰り返しにはならない。

### 🚪 ゲート（増減）
道が左右 2 枚に区切られ、通った側の演算が弾数に適用される。**1 つ目は必ずゲート**
（まず育ててから戦わせる）。

| 当たり | はずれ |
|---|---|
| `×2` `×3` `×4` `+8` `+15` | `÷2` `÷3` `-6` `-12` |

- 60%：当たり × はずれ／25%：当たり × 当たり／15%：はずれ同士（このときは `÷` のみ）
- 撃つたびに **50% で左右入れ替え、35% で片側を引き直し**

### 🐵 サル（通行料）
**1 匹につき果物 1 個**の通行料を取る。倒す相手ではない。
弾がゼロになるとその発は終わり（ダメージ 0）。
**左右にうろうろ**しているので、毎回ねらいどころが変わる。

### 🍒 ボーナス
道に落ちている大きな果物。拾うと `+6〜14`。位置は毎回変わる。

### 🐻 クマ（坂の底）
届いた弾数がそのままダメージ。HP は `150 + ステージ×70`（ステージ1 = 220）。
9 発撃ち切ってもゼロにできなければゲームオーバー。

## 5. バランス（ヘッドレス実測 / ステージ1）

| 撃ち方 | 結果 |
|---|---|
| ねらいランダム・軌道修正なし | 9 発で HP 250 → 226（ほぼ削れない） |
| ゲートの得な側を選び、サルを避ける | **1 発あたり 28〜56 ダメージ、7 発でクリア** |

- 初弾は **6 個**スタート。良いルートなら `6 →×3→ 18 →×4→ 72` まで伸びる。
- 悪いルートだと `6 →÷2→ 3 → サル5匹 → 0`。振れ幅が大きいのが狙い。
- **残弾 2 発を残してクリアできる**のが上手い人の目安。スコアは `残弾×120 + ステージ×200`。

## 6. 絵づくり

**生き物はすべてシルエット**（`#20232b` のベタ）。人間・サル・クマは形と動きだけで見せ、
色は果物にだけ与える。これで「色のついた果物の群れ」対「黒い影」のコントラストが立つ。

- **人間**：背中side。果物を右手に下げて構え、撃つと前に振り抜く。手の中の果物＝残弾の合図。
- **サル**：しっぽのカーブで種類がわかるシルエット。**目だけ黄色く光る**。
- **クマ**：ずんぐりした大きな影。**目だけ赤く光る**。被弾すると色が浮いて小刻みに揺れる。
- **果物**：3 トーン（ベタ＋硬い影＋ハイライト）＋回転するスジ。顔はつけない。
- 背景は擬似 3D の坂道。画面比からカメラ高さと消失点を自動調整（縦長スマホ／横長 PC 対応）。

## 7. 技術メモ

- **依存ライブラリなし**。`index.html` + `game.js` の 2 ファイル。画像素材ゼロ。
- Canvas 2D の **1 点透視**。`scale = 焦点距離 / 奥行き` に「奥ほど沈む」項を足して下り坂を表現（`project()`）。
- 弾は 1 個だけ。`S.ball = { x, z, vx, count }` を進め、`prevZ < item.z <= z` でコース要素と判定する。
- 壁（道の端）で **反射**する。予測線は同じ計算を 46 ステップ先まで回して描いている。
- 効果音は WebAudio のオシレータ生成。音源ファイル不要。
- QA 用に `window.CrowdRunner`（`state` / `startStage` / `fire` / `setAim` / `pause` / `art`）を公開。
  ヘッドレス Chromium から自動プレイしてバランスを測っている。

### 動かし方
```bash
python3 -m http.server 8000
# → http://localhost:8000/crowd-runner/
```

## 8. 今後の拡張アイデア

| 優先 | アイデア | ねらい |
|---|---|---|
| 高 | **弾の種類**（重い＝曲がらない／軽い＝よく跳ねる／爆ぜる） | 撃ち分けの戦略 |
| 高 | **チャージショット**（長押しで初速が上がる＝速いが曲げにくい） | 操作の幅 |
| 高 | クマの**反撃**（数発ごとに前に出てきてレーンを狭める） | 終盤の緊張 |
| 中 | レーンの**分岐**と、坂のカーブ | コースの読み |
| 中 | サルが果物を**投げ返してくる** | 障害の変化 |
| 低 | リプレイ動画の書き出し（縦 9:16） | SNS 拡散 |
| 低 | ランキング・デイリーチャレンジ | 継続率 |

### 収益化の想定
- 9 発撃ち切って倒しきれなかったときの **リワード広告で +3 発**（一番惜しい瞬間に出す）
- ステージ間インタースティシャル / スキンの買い切り
