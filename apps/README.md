# くらし四部作 — 叩き台プロトタイプ

日常生活の四大ペイン（献立・お金・睡眠・運動）に対する4本のアプリの叩き台。
すべて単一HTMLファイルで動作し、データはブラウザのlocalStorageに保存されます。
ブラウザで各ファイルを開くだけで試せます。

| ファイル | アプリ | コンセプト |
|---|---|---|
| `konya-kore.html` | 今夜これ | 開いた瞬間、今夜の献立が決まっている。提案・リロール・買い物リスト |
| `atoikura.html` | あといくら | 記録ではなく残額を見る家計簿。予算設定・テンキー入力・残額ゲージ |
| `nemuri-lab.html` | ねむり実験室 | 毎晩1つの習慣を実験し、朝の疲労感から「効く習慣」を特定 |
| `sanpun-taiso.html` | 三分体操 | 着替えない・器具なし・3分。日替わりメニュー・タイマー・連続記録 |

## 共通設計原則

- 1画面主義（開いて3秒で用が済む）
- 判断の肩代わり（選択肢を減らして「これ」と提示する）
- 記録はワンタップ以内
- データは端末内完結（この叩き台ではlocalStorage）

企画の詳細・需要データの出典は企画書「くらし四部作」参照。
