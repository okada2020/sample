# 楽天ROOM / note 実運用プラン(放置検証用)

## 結論

**完全放置は成立しない。** 内訳:

| やりたいこと | 判定 |
|---|---|
| 自動投稿ツールで放置 | **規約違反**。報酬没収 + アカウント停止 |
| 何もせず本当に放置 | 規約上セーフ。ただし収益はほぼ確実にゼロ |
| 初期構築だけして放置 | 規約上セーフ。**これが検証すべきライン** |

「規約内で放置すると0円」ということ自体が検証結果になる。
そこを実測するのがこのシリーズの価値。

---

## 1. 楽天ROOM

### 規約で禁止されていること(一次情報)

楽天ROOM利用規約 第11条(禁止事項)(4):

> スクリプトその他のプログラムを実行する等の方法により、
> 機械的にコレ!、コメント等をする行為

違反時の措置として規約に明記されているもの:

- 投稿の削除
- ROOMの利用停止、資格の取り消し
- **成果報酬(ポイント)の取り消し**

つまり自動化ツールでBANされると、**それまでの未確定報酬も消える**。
報酬は発生から確定まで約2ヶ月かかるので、消える額は想像より大きい。

### やってはいけないこと

| 行為 | 理由 |
|---|---|
| 自動いいね / 自動フォロー / 自動投稿ツール | 第11条(4)直撃。市販ツールも例外ではない |
| クラウド型AIエージェント(Manus等)での操作 | データセンターIPがbot判定されやすい |
| 短時間に大量のいいね | 手動でも「機械的」と判定され得る。非公式だが上限は1時間300 / 1日1000と言われる |
| 自己購入・家族間の相互購入 | 異常購入と判定された停止事例あり |
| 外部ツールに楽天IDとパスワードを渡す | 楽天ID全体の停止 = 楽天市場も使えなくなる |
| SNSにROOMリンクを貼るときPR表記なし | ステマ規制(2023年10月施行) |

### セーフなライン

> **下書きまで効率化、投稿ボタンは自分の指で押す**

AIに使わせていいのは「商品選定」「紹介文の下書き」「画像加工」まで。
ROOMへの投稿・いいね・フォローのクリックは必ず手動。

### 検証の設計

3本立てにすると比較が出る。

| レベル | 内容 | 測るもの |
|---|---|---|
| L0 完全放置 | アカウント作成 + 20投稿して30日放置 | 世間の「放置」主張の実測値 |
| L1 最小メンテ | L0 + 週1回20分だけ投稿追加 | 最小工数の損益分岐 |
| L3 全力 | 毎日3時間(世間の「放置」の実態) | L0との差 = 労働の対価 |

L3は1週間だけでいい。**L0とL3の差がそのままコンテンツになる。**

### 初期コスト

0円。楽天IDとスマホだけ。金銭リスクは無い。
リスクは楽天ID停止のみなので、**サブの楽天IDで始めること**。

## 2. note

### AI記事は禁止されていない

note利用規約とコミュニティガイドラインを読んだ範囲では、
AIで書くことを禁止する条文も、AI利用の明記を求める条文も存在しない。

禁止されているのは **AIかどうかではなく行為**:

- 機械的な大量投稿、スパム行為
- 盗作・剽窃
- 「必ずもうかる」等の著しい誤解を招く表現
- 景品表示法違反、またはそのおそれ
- **確定・未確定を問わず売上・利益を公開して、購入を煽る行為**
- 自己取引による現金化(2026年1月15日の改定で明文化)

### ★このシリーズで一番注意すべき条項

クリエイター規約 10.1(3):

> 確定・未確定を問わず売上、利益その他これに類するものを公開して、
> 本サービス上で配信するデジタルコンテンツや各種サービスの購入を煽る場合

**「公開」と「煽る」の2つが揃って初めてアウト。**

このシリーズは収益公開が本体なので、ここを踏まない設計にする:

| | 判定 |
|---|---|
| 「30日で¥147でした」と書く(無料記事) | セーフ |
| 「30日で¥147でした。詳しい手順はこの有料記事で」 | **アウト寄り。やらない** |
| 「月30万稼いだ方法を5,000円で販売」 | アウト |

**このシリーズのnote記事は全部無料にするのが最も安全。**
収益化はアフィリエイトか、実績が貯まってから別立てで考える。

なお運営は「どこまでがセーフか」の個別回答をしない。最終的に運営の裁量。

### 違反したときに失うもの

規約上、違反が悪質または複数回の場合:

- 事前通知なしで利用停止
- 販売済みコンテンツの代金の支払い拒否、**違約金として没収**
- 支払い済みの場合は返金請求
- 事務手数料の請求

### 2026年2月の対応強化(公式発表)

> 機械的に大量の記事を投稿する行為やスパム投稿行為、
> その他これらの類似行為に対して、段階に応じた適切な措置を行っていきます。
> 外部サービスを利用した組織的な悪用行為や迷惑行為も確認されています。

軽微なら事前通告から、悪質なら利用停止。組織的な場合は法的措置も検討。

### 手数料(収益計算に必須)

| 項目 | 率 |
|---|---|
| 事務手数料 | 5% |
| プラットフォーム利用料 | (代金 - 事務手数料)の10% |
| 決済手数料 | 決済方法による |
| **手取り** | **販売価格の約8割** |

- 受け取り申請は売上1,000円以上から
- 確定から180日以内に申請
- 有料販売するなら特定商取引法に基づく表示が必要

### 検証の設計

| レベル | 内容 |
|---|---|
| L0 完全放置 | AI下書き + 人が加筆した記事を10本入れて30日放置 |
| L1 最小メンテ | L0 + 週1本追加 |

noteはストック型(検索流入が数ヶ月後に効く)なので、
**30日では結論が出ない可能性が高い**。90日まで追うか、
「30日では判定不能だった」自体を結果として出す。

### AI学習対価還元プログラム

- デフォルトON。設定 → 記事設定 から切替
- 実証実験の平均は4,105円だが参加者1,218人限定。分母が増えれば希薄化する
- **これ目当てで記事を量産すると上の「機械的大量投稿」に直撃する**
- 参加するのは構わないが、収益見込みに入れない

## 3. 開始前チェックリスト

- [ ] 楽天はサブIDで登録した(メインIDを巻き込まない)
- [ ] 楽天IDに二要素認証を設定した
- [ ] 外部ツールにログイン情報を渡していない
- [ ] 自動化ツールを一切入れていない
- [ ] noteの記事は全部無料に設定した(10.1(3)回避)
- [ ] SNSでリンクを貼るとき「PR」を明記する運用にした
- [ ] 「誰でも稼げる」等の断定表現を使わない方針を明文化した
- [ ] 作業時間を記録する仕組みを用意した(時給換算に必須)
- [ ] 開始日・投稿本数・初期コストを記録した

## 4. 記録テンプレ

検証の生データ。これが無いと時給換算ができない。

```
日付 / 媒体 / 作業内容 / 作業時間(分) / 投稿数 / クリック / 売上 / 累計
```

`sns/log.csv` に貯めていく。
