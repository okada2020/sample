# リプライ営業の相手の探し方

フォロワー0から配信経路を作るための作業手順。
「誰にリプするか」を固定リストで持つと古くなるので、検索で毎回掘る。

---

## 狙う相手の規模

| フォロワー | 扱い |
|---|---|
| 5万〜(深津さん、チャエンさん等) | **リプ営業には使わない。** 1投稿に数百リプ付くので埋もれる。ネタ元としてフォローするだけ |
| **1,000〜2万** | **本命。** リプが読まれるし、返信が返ってくる。ここに集中する |
| 〜500 | 同格。相互に伸びる仲間になり得る。無理に狙わなくていい |

大手に0番目でリプできるなら効くが、通知を張る運用は消耗するので推奨しない。

---

## 検索クエリ

X の検索窓にそのまま貼る。スマホアプリの検索窓でも動く
(「高度な検索」の画面はPCブラウザのみだが、コマンド自体はどこでも動く)。

### 本命:直近で伸びている投稿に乗る

投稿から24時間以内 × すでに反応がある = リプが一番読まれる状態。

```
楽天ROOM min_faves:10 lang:ja within_time:24h -filter:replies -filter:retweets
```

```
(AI副業 OR "AIで稼ぐ" OR "AI 収益化") min_faves:20 lang:ja within_time:24h -filter:replies -filter:retweets
```

```
個人開発 (リリース OR 収益 OR 売上) min_faves:20 lang:ja within_time:24h -filter:replies
```

### 自分のデータが武器になるやつ

調べた数字(報酬率1〜4%、時給¥1.77、note平均¥4,105 など)を
そのままリプに使える話題。

```
("不労所得" OR "放置で" OR "寝てる間に") (AI OR 副業) min_faves:30 lang:ja -filter:replies
```

```
(note 有料記事 OR note 収益) (売れない OR 伸びない) min_faves:20 lang:ja -filter:replies
```

```
楽天ROOM (稼げない OR 収益 OR 現実) min_faves:20 lang:ja -filter:replies
```

### 「あったらいいな」シリーズ用

こちらの方が競合が薄く、反応も返ってきやすい。

```
(ADHD OR 発達障害 OR LD) (困りごと OR "あったらいいな" OR アプリ) min_faves:30 lang:ja -filter:replies
```

```
("何しようとしてたんだっけ" OR "置いた場所" OR "忘れ物") min_faves:50 lang:ja -filter:replies
```

### ネタ元(フォローして観察するだけ)

リプはしない。ネタと書き方を盗む用。

```
(AI OR 生成AI) 検証 min_faves:200 lang:ja -filter:replies -filter:retweets
```

---

## 注意

`min_faves:` `min_retweets:` `within_time:` は **X の公式ヘルプに記載のない
非公式コマンド**。長年動いているが、仕様変更で予告なく止まる可能性がある。
動かなくなったら数値条件を外すか、PCブラウザの「高度な検索」を使う。

書式でよくある失敗:
- 全角スペースを使っている(半角のみ)
- ダブルクォートが全角(`"` は半角)
- コロンの後ろにスペース(`from: ID` ではなく `from:ID`)

---

## リプの書き方

**ダメな例**(やっても意味がない)
- 「勉強になります!」
- 「その通りですね」
- 絵文字だけ

**効く例**(数字を足す)

> 楽天ROOMの報酬率、商品価格の1〜4%なんですよね。
> 月3万だと月75万〜300万円分を売る計算になるので、
> 「スマホでポチポチ」の解像度がだいぶ違うなと。

> note の AI学習還元、実証実験は参加1,218人で平均4,105円でした。
> ただ最高額が40万超なので、平均で判断すると事故りそうです。

**原則**
- 自分の持っている数字を1つ足す
- 相手を否定しない。情報を足すだけ
- 宣伝しない。プロフィールに来てもらえば十分
- 1日10〜15件。それ以上はスパム判定のリスク
