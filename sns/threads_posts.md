# X → Threads 投稿書き換えガイド & 下書き

対象アカウント: 出張シェフ / ケータリング（`病院/cooking/` のサイト）

> ※ 元の X 投稿文がまだ手元にないため、サイト掲載内容（コースメニュー・ケータリングプラン・
> アレルギー対応）をもとに「X 版（想定）→ Threads 版」の形でサンプルを作成しています。
> 実際の X 投稿文をいただければ、同じルールでそのまま書き直します。

---

## 1. 書き換えルール（X と Threads の違い）

| 項目 | X | Threads | 書き換え方針 |
|---|---|---|---|
| 文字数 | 140字（無料枠） | 500字 | 削って詰め込んだ文を、主語・情景を戻して自然な文章に |
| ハッシュタグ | 複数併用が一般的 | 実質1つ（トピックタグ）のみ機能 | タグを1つに絞り、残りは本文の言葉に溶かす |
| 外部リンク | 通常運用 | リンク付き投稿は伸びにくい | 本文だけで完結させ、URL は返信 or プロフィールへ |
| 画像 | 横長中心 | 正方形〜縦長が映える／複数枚 | 料理写真は縦位置・寄りのカットを優先 |
| トーン | 告知・速報 | 会話・独り言・裏側の共有 | 宣伝色を薄め、問いかけで締めて返信を促す |
| 長文 | 削るか画像化 | 返信でつなぐ（スレッド） | 補足・価格詳細は1件目の返信に分ける |

**共通の型**: 情景や一言 → 中身（料理／プラン） → 問いかけ。価格や連絡先は返信に逃がす。

## 2. サンプル投稿

### (1) コースメニュー告知

**X 版（想定）**
```
【出張シェフ】コースA ¥4,000 / コースB ¥10,000 で承ります。前菜・スープ・メイン・デザート付き。
アレルギー対応可◎ DMまで
#出張シェフ #ケータリング #フレンチ #記念日
```

**Threads 版**
```
「家で、外食みたいな一日を」

前菜、スープ、メイン、デザート。
お店の一皿をそのままご自宅のテーブルまでお持ちします。

コースは2種類。
気軽に頼めるものと、記念日にしっかり出すもの。
苦手な食材やアレルギーがあれば、その場で組み替えます。

次の記念日、家でやるとしたら何を食べたいですか？

#出張シェフ
```
> 返信に置く内容: `menuA ¥4,000 / menuB ¥10,000（税込）・ご相談はプロフィールのフォームから`

## 3. 運用メモ

- 投稿は本文だけで完結させ、URL は必ず1件目の返信へ。
- 1日1〜2投稿。うち1本は (4)(6) のような宣伝色のないものを混ぜる。
- 返信が付いたら本文と同じトーンで返す（Threads は返信もタイムラインに露出する）。
- 画像は縦位置（4:5）を優先。料理は寄りのカットが強い。
