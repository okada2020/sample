# FAX 発信元サーチ

FAX番号を含むCSVまたはPDFを読み込み、公開ウェブ情報を検索して、番号ごとの発信元候補・確度・根拠URLを一覧にするWebアプリです。ローカル実行とCloudflare Workersへの公開に対応します。

## 起動

Node.js 22.13以降が必要です。

```bash
npm install
cp .env.example .env
npm start
```

`npm start`は起動前に`scripts/sync-vendor.mjs`を実行し、PDFの解析に使うpdf.jsを
`public/vendor/`へ配置します。`public/`はバンドラを通さずそのまま配信されるため、
この配置がないとブラウザ側のスクリプトが読み込めません。

ブラウザで `http://localhost:4173` を開きます。

安定した検索には `.env` の `BRAVE_SEARCH_API_KEY` を設定してください。未設定でもDuckDuckGoの公開HTML検索で試せますが、アクセス制限や検索仕様変更の影響を受ける可能性があります。APIキーはサーバー側だけで読み込まれ、ブラウザには送信されません。

## CSV

- UTF-8 / Shift_JIS（ブラウザが対応している場合）
- カンマ、タブ、セミコロン区切り
- `FAX`、`FAX番号`、`ファックス`、`電話番号` などの列名を自動検出
- 引用符、セル内カンマ、改行に対応

## PDF

- 文字を選択・検索できるPDFからFAX番号を自動抽出
- 全角数字、一般的なハイフン表記、`+81` / `0081` の国際形式に対応
- 市外局番の桁数（2〜5桁）に合わせて区切り位置を判定（例: `0463-21-1111`、`01267-2-2111`）
- 送信票ヘッダの受信日時（`08/24/2026 09:30` など）を番号として拾わない
- 20MB・100ページまで
- 画像だけのスキャンPDFとパスワード保護PDFには非対応

PDFの解析はブラウザ内で行い、抽出した番号だけを検索処理に使用します。画像だけのPDFは、OCR済みの検索可能なPDFへ変換してから読み込んでください。

処理後は元の列を保ったまま、以下の列を加えたCSVをダウンロードできます。

- `検索状態`
- `推定発信元`
- `確度`
- `根拠URL`
- `根拠要約`
- `検索クエリ`

## 番号の表記ゆれ

FAX番号の書き方は取引先ごとにばらばらです。次の書き方はすべて同じ番号として読み取ります。
`examples/mixed-formats.csv` に一通り入れてあります。

| 種類 | 例 |
| --- | --- |
| 区切り記号 | `03-1234-5678` `03(1234)5678` `03.1234.5678` `03・1234・5678` `03 1234 5678` |
| ハイフンの種類 | `-` `‐` `–` `—` `ー` `−`（全角マイナス）も同じ扱い |
| 全角 | `０３－１２３４－５６７８` |
| ラベル付き | `FAX:03-1234-5678` `ＦＡＸ　03-1234-5678` `℡03-1234-5678` |
| 国際表記 | `+81-3-1234-5678` `+81 (0)3 1234 5678` `0081-3-…` `81-3-…` |
| 内線・代表 | `03-1234-5678 内線123` `03-1234-5678（代）` |
| 1欄に複数 | `TEL 03-1234-5677 FAX 03-1234-5678` `03-1234-5678／03-1234-5679` |
| 漢数字 | `〇三－一二三四－五六七八` |

補正したときは、その旨を結果画面と出力CSVに残します。

**Excelで先頭の0が落ちた番号**（`312345678`）は、0を補った結果が実在する市外局番のときだけ補正します。
当てずっぽうでは直しません。`3.12346E+09` のような指数表記は元の桁が失われているため補正できず、
「セルを文字列にして入力し直してください」と表示します。

1つの欄に複数の番号があるときは、`FAX`のラベルが近い方を採用し、もう一方は「同じ欄にあった他の番号」として残します。

読み取れなかった値には、桁が足りないのか、番号帯が存在しないのか、理由を添えます。

## 判定について

検索結果のタイトル・要約に番号そのものが掲載されているか、複数結果で組織名やドメインが一致するかを基に確度を算出します。結果は本人確認や権利関係を保証するものではありません。公開情報の候補として、必ず根拠URLを開いて確認してください。

入力CSV・PDFや検索結果はサーバーに保存しません。

## Cloudflare Workersへ公開

```bash
npm install
npm run cf:types
npm run cf:dry-run
npx wrangler login
npm run deploy:cloudflare
```

公開版の一度の検索上限は25件です。Workerのサブリクエスト数と検索APIの利用量を抑えるための上限で、CSVを分割すれば続けて検索できます。

安定運用ではBrave Search APIキーをCloudflareのシークレットに設定してください。値をソースコードや `wrangler.jsonc` に書かないでください。

```bash
npx wrangler secret put BRAVE_SEARCH_API_KEY
```

設定後はアプリ右上に「Brave Search 接続済み」と表示されます。キーがない場合はDuckDuckGoの試用検索を使用します。

## 限定公開にする

`ACCESS_PASSWORD` を設定すると合言葉の入力画面が前に立ち、知っている人だけが使えるようになります。
画面もPDFの解析ファイルもAPIも、合言葉を通るまでは配信しません。未設定なら従来どおり、
URLを知っている人は誰でも開けます。

Cloudflareへ公開したものを限定公開にする場合:

```sh
npx wrangler secret put ACCESS_PASSWORD
npm run deploy:cloudflare
```

ローカルで試す場合は `.env` に書きます。

```sh
ACCESS_PASSWORD=長めの合言葉をここに
```

合言葉そのものはブラウザへ渡さず、12時間で切れる署名付きのCookieだけを渡します。
右上の「ログアウト」で明示的に切ることもできます。共有パソコンで使ったあとや、
合言葉を知る人が変わったときは、`wrangler secret put` で入れ直してください。
入れ直すと、それまでのログイン状態はすべて無効になります。

一人ずつメールアドレスで制限したい場合は、独自ドメインを Cloudflare に登録したうえで
Cloudflare Access を使う方法もあります。

## 市外局番テーブル

`public/jp-area-codes.js`は自動生成ファイルです。日本の市外局番は2桁から5桁まであり、
区切り位置は市外局番と市内局番を合わせた先頭6桁で決まります。総務省の改定に追従するときは
次のコマンドで作り直してください（`libphonenumber-js`は開発時のみ使用します）。

```sh
npm run areacodes
npm test
```

`npm test`には、生成した表が`libphonenumber-js`と全番号帯（10万通り）で一致することを
確認するテストが含まれています。
