# Instagram フォロワー 100 → 1,000 ロードマップ

対象アカウント: 映画・ドラマ・動画配信（VOD）の情報発信。
最終的な目的は「VOD比較ナビ」（`affiliate/`）への送客とアフィリエイト成約。

---

## 0. 先に押さえる前提

### フォロワーは「保存数」の結果でしかない

2020年代の Instagram は、フォロワー外へのリーチをリール（と発見タブ）が担う。
アルゴリズムが評価する順番はおおよそ次のとおり。

1. **視聴維持率**（最後まで見たか / 2回以上見たか）
2. **保存**（あとで見返す価値があるか）
3. **シェア**（DM・ストーリーズで人に送ったか）
4. いいね・コメント
5. プロフィールアクセス → フォロー

つまり「フォロワーを増やす施策」を直接やるのではなく、
**保存とシェアが起きる投稿を量産する** → その副産物としてフォロワーが増える、という順序になる。

### 数字の逆算

一般的な水準として、リーチ→フォローの転換率は **0.5〜2%**（プロフィールが整っていれば1%前後）。

| 目標 | 必要な追加フォロワー | 必要な累計リーチ（転換率1%想定） |
|---|---|---|
| 100 → 300 | +200 | 約 20,000 |
| 300 → 600 | +300 | 約 30,000 |
| 600 → 1,000 | +400 | 約 40,000 |
| **合計** | **+900** | **約 90,000** |

リール1本あたりの平均リーチを 1,500 とすると **約60本**。
週4本ペースなら **約15週（3〜4か月）**、週5本なら **約12週**。
これが現実的な所要時間の目安であり、「1か月で1000人」は買うか運任せのどちらか。

## 1. Phase 0（1週間）｜土台を作る

フォロワー100人の段階でリーチを増やしても、プロフィールが弱いとフォローに変わらない。
**先にここを直すのが投資効率として最も高い。**

### プロフィール

- **名前欄（検索対象）**: 「サービス名｜ジャンル+ベネフィット」の形式にする。
  例: `映画えらび / VOD比較` — 名前欄はハッシュタグ検索ではなくキーワード検索に効く。
- **自己紹介**: 1行目に「誰の・何の悩みを解決するか」。
  例: `「今夜どれ観る？」を3分で解決 / 主要7社を実費契約して比較`
- **リンク**: `affiliate/` のトップではなく **3問診断ページ** に直接飛ばす（離脱が減る）。
- **ハイライト**: 「はじめまして」「料金比較」「無料体験」「今月の新作」の4つを最低限。
- **プロアカウントに切替**（インサイトが見られないと以降の改善ができない）。

### 発信テーマの固定

「映画全般」は広すぎて誰もフォローしない。次のどれか1つに寄せる。

- 「サブスク代を下げたい人」向けの節約軸
- 「今夜観るものを決めたい人」向けの選択支援軸
- 特定ジャンル（韓国ドラマ / アニメ / 海外ドラマ）特化軸

サイト側の記事（`affiliate/data/content.js`）と軸を揃えると、
Instagram の投稿がそのまま記事の導線になり、制作コストが半分になる。

## 2. Phase 1（〜4週）｜100 → 300：型を見つける

### やること

- **リール 週4本**。ここでは「当たる型」を探すための試行回数がすべて。
- 1本あたり **15〜30秒**、最初の1秒で結論を出す。
- 全投稿を「保存される理由」から逆算する（=一覧性・比較表・手順）。

### 当たりやすい投稿の型（このジャンルで実績が出やすい順）

1. **比較表**: 「主要7社を1枚にまとめた」→ 保存の王道
2. **数字で驚かせる**: 「サブスク見直したら年24,000円浮いた話」
3. **失敗回避**: 「無料体験で課金される人がやりがちな3つのミス」
4. **リスト**: 「◯◯が観られるのはこの2社だけ」
5. **時期もの**: 「今月終了する作品まとめ」→ 毎月使える定番枠
6. **手順**: 「解約を3タップで終わらせる方法」
7. **診断**: 「3問であなたに合うVODが分かる」→ プロフィールリンクへ直結

### 最初の1秒の作り方

- テキストは **画面上部1/3に置かない**（UIに隠れる）。
- 「〜について解説します」は禁止。**結論・数字・否定形**から入る。
  - 悪い例: 「VODの選び方を解説します」
  - 良い例: 「Netflix、実は損してるかも」

### 判定基準（4週間後）

- 平均リーチ 1,000 超え → 型が見つかっている。Phase 2 へ
- 平均リーチ 300 以下 → 冒頭1秒とテーマ設定を作り直す。本数を増やしても解決しない

## 3. Phase 2（5〜10週）｜300 → 600：勝ち筋を増幅する

### やること

- **伸びた投稿の続編を作る**。1本当たったら、同じ型で5本作る。
  新しいアイデアを探すより、当たった型の横展開のほうが期待値が高い。
- **投稿頻度を週5本**に上げる（リール4＋カルーセル1）。
- **ストーリーズを毎日**。既存フォロワーとの関係維持は、
  新規リーチのアルゴリズム評価にも効く。質問スタンプ・アンケートを週2回以上。
- **コメント返信を投稿後1時間以内に全件**。初速のエンゲージメントが配信量を決める。

### カルーセル（複数画像）の使いどころ

リールは新規リーチ、カルーセルは保存を取る。
「7社比較表」「今月の新作カレンダー」のような **1枚目で完結させず、
最後のページに『保存推奨』とサイト誘導** を置く構成にする。

### コラボ

同規模（500〜3,000フォロワー）のアカウントとの共同投稿（コラボ機能）は、
相手のフォロワーにそのまま配信されるため、この段階で最も費用対効果が高い。
月2〜3件を目標に、DMで具体的な企画（例:「韓ドラ好き向け5選を共同で」）を持ちかける。

---

## 4. Phase 3（11〜16週）｜600 → 1,000：仕組みにする

- **投稿カレンダーの固定化**: 月曜=比較、水曜=新作、金曜=節約術、日曜=まとめ
  のように曜日でフォーマットを固定すると、制作時間が1本30分程度まで下がる。
- **ストック活用**: 過去の当たり投稿を3か月後に作り直して再投稿する
  （フォロワーの大半は初見のため、実質新規コンテンツとして機能する）。
- **サイト送客の計測開始**: プロフィールリンクに UTM を付け、GA4（`site.js` の `ga4Id`）で
  Instagram 経由の `affiliate_click` を追う。
  例: `https://vod-navi.pages.dev/?utm_source=instagram&utm_medium=bio`
- **フォロワー数より送客数**: 1,000人を超えたら、KPIを
  「フォロワー数」から「月間サイト送客数・成約数」に切り替える。

## 5. 週次の運用ルーティン（所要 約5時間）

| 曜日 | 作業 | 時間 |
|---|---|---|
| 月 | 先週のインサイト確認、伸びた投稿の特定、今週の5本を企画 | 60分 |
| 火 | 撮影・素材作成をまとめて実施（バッチ制作） | 120分 |
| 水 | 編集・予約投稿の設定 | 90分 |
| 木〜日 | 投稿直後1時間のコメント返信、ストーリーズ毎日1本 | 各15分 |

**バッチ制作（1日でまとめて作る）が続けるための最大のコツ。**
毎日ゼロから作ろうとすると3週間で止まる。

## 6. 数値管理

毎週この5項目だけ記録する（多すぎると続かない）。

| 週 | 投稿数 | 平均リーチ | 平均保存数 | プロフ アクセス | フォロワー増 |
|---|---|---|---|---|---|
| W1 | | | | | |
| W2 | | | | | |

### 見るべき比率

- **保存率 = 保存数 ÷ リーチ**: 1%以上なら良い、2%超なら伸びる
- **フォロー転換率 = フォロワー増 ÷ リーチ**: 1%未満ならプロフィールの問題
- **プロフィールアクセス率**: 高いのにフォローされない = 自己紹介文が弱い

問題の切り分けはこの順で行う。
リーチが低い → 冒頭1秒 / リーチはあるがフォローされない → プロフィール。

## 7. やってはいけないこと

- **フォロワーの購入**: エンゲージメント率が壊れ、以後の配信が伸びなくなる。回復は困難。
- **フォロー&アンフォロー**: 短期的には増えるが、興味のないフォロワーが増えると
  保存率が下がり、結果としてリーチが落ちる。1,000人に到達しても意味がない。
- **相互フォロー企画**: 同上。数字だけが残り、成約はゼロになる。
- **予告編・本編映像の無断転載**: 著作権侵害。アカウント削除リスクがあり、
  ここまでの資産を一度に失う。公式配布素材・自分で撮った画面外の素材・
  自作グラフィックで構成する。
- **PR表記の省略**: 2023年10月からステマは景表法違反。アフィリンクを含む投稿・
  ストーリーズには必ず `#PR` を明記する（サイト側の `prLabel` と同じ扱い）。

## 8. 最初の7日間でやること

1. プロフィール（名前欄・自己紹介・リンク）を書き換える
2. 発信テーマを1つに決める
3. ハイライト4本を作る
4. 「主要7社比較表」のリールを1本作る ← 最初の1本はこれが最も当たりやすい
5. 上記の型リストから10本分のネタを書き出す
6. 火曜に5本まとめて撮る
7. 週の投稿4本を予約設定する
