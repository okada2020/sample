# Instagram フォロワー 100 → 1,000 ロードマップ（料理人・個人アカウント）

対象: `@bistro_man1` — 料理人個人としての発信
最終目的: **仕事・案件の依頼**（レシピ開発 / 監修 / 出張料理 / 撮影 / PR案件）
制作リソース: 週3〜4本 / 約3時間

---

## 0. 目的から逆算した「正しい1,000人」

先に結論を書く。**案件依頼を目的にする場合、1,000という数字そのものには価値がない。**
発注側（飲食店経営者、食品メーカーの販促担当、PR代理店、編集者）が見ているのは次の3つ。

1. **この人は本当に作れるのか**（技術の証拠）
2. **依頼したら何をしてくれるのか**（提供メニューの明示）
3. **投稿がちゃんと届いているか**（フォロワー数ではなくエンゲージメント率）

フォロワー1,000人でエンゲージメント率8%のアカウントには依頼が来るが、
1万人で0.5%のアカウントには来ない。だから本計画では、
**数を追う施策と、依頼が来る状態を作る施策を、同時に走らせる。**

### 数字の逆算

リーチ→フォロー転換率は、プロフィールが整った専門アカウントで **1〜2%**。
料理系は視覚的に強く、専門性が伝わりやすいため上限側に寄りやすい。

| 目標 | 追加フォロワー | 必要な累計リーチ（転換率1.2%想定） |
|---|---|---|
| 100 → 300 | +200 | 約 17,000 |
| 300 → 600 | +300 | 約 25,000 |
| 600 → 1,000 | +400 | 約 33,000 |
| **合計** | **+900** | **約 75,000** |

リール1本あたりの平均リーチを 1,500 とすると **約50本**。
**週3.5本ペースで約14週＝3.5か月**、立ち上がりの遅れを見込んで **4〜6か月** が現実的。

## 1. Phase 0（1週間）｜依頼が来る状態を先に作る

フォロワー100人の段階でリーチだけ増やしても、プロフィールが弱ければフォローに変わらず、
依頼窓口がなければ案件にも変わらない。**ここが最も投資効率が高い。**

### プロフィールの5要素

料理人アカウントは、この5つが揃っているかで依頼の有無がほぼ決まる。

| 要素 | 書くこと | 例 |
|---|---|---|
| 名前欄（検索対象） | 職種＋ジャンル | `シェフ ◯◯ / フレンチ・ビストロ料理` |
| 1行目 | 経歴＝信頼の根拠 | `都内ビストロ 総料理長 / 仏修業3年` |
| 2行目 | 誰の何を解決するか | `家庭のフライパンで店の火入れを再現` |
| 3行目 | **提供メニュー** | `レシピ開発・監修・出張料理承ります` |
| 4行目 | **依頼導線** | `ご依頼はDM または プロフィールのリンクへ` |

- **顔と本名（または一貫した名前）を出す。** 匿名の料理人に企業は発注できない。
- **リンク**: 依頼フォーム（Googleフォームで十分）か、経歴＋実績＋料金の1枚ページ。
  依頼導線が「DMのみ」だと、法人担当者は社内稟議の資料が作れず離脱する。

### ハイライト4本（＝ポートフォリオ）

1. **実績** — 過去の仕事、掲載、提供した料理
2. **ご依頼について** — 何を、いくらで、どのくらいの期間で
3. **プロフィール** — 経歴を1本の動画かカルーセルで
4. **人気の投稿** — 保存が多かったものをまとめる

発注担当者はフィードを遡らない。**ハイライトが実質の営業資料**になる。

### 発信テーマを1つに絞る

「料理全般」では誰もフォローしない。料理人の強みが最も立つのは次の軸。

- **「店の技術を家庭で再現する」軸** ← 最も汎用性が高く、案件にも直結する
- 特定ジャンル特化（フレンチ / ビストロ / 肉料理 / ソース）
- 「プロは家でこう作る」軸（時短・少ない道具）

推奨は1つ目。理由は、家庭再現の翻訳ができる料理人は
**食品メーカーのレシピ開発案件と要求スキルが完全に一致する**ため、
発信がそのままポートフォリオになる。

## 2. Phase 1（〜5週）｜100 → 300：技術を「見せる」型を見つける

### やること

- **リール 週3〜4本**。この段階は当たる型を探す試行回数がすべて。
- **1本 20〜40秒**、最初の1秒は「手元」か「音」で掴む。
- 料理人アカウント最大の武器は **技術そのものの映像**。喋りは要らない。

### 当たりやすい投稿の型（料理人アカウントで実績が出やすい順）

1. **プロの手元**
   包丁さばき、火入れ、乳化、盛り付け。無音・字幕なしでも成立する。最も拡散する。
2. **「店ではこうやってる」**
   家庭との違いを1点だけ見せる。例:「肉を焼く前に絶対やること」→ 保存の王道。
3. **常識の否定**
   「パスタの茹で汁に油を入れるな」「焼く直前に塩を振るな」。理由を10秒で説明する。
4. **失敗の原因解説**
   「玉ねぎ炒めが茶色くならない理由」。検索需要があり、長期間リーチし続ける。
5. **1食材を極める**
   「じゃがいも1個でできる3品」。保存されやすい。
6. **道具・食材の選び方**
   プロ目線の判断基準。メーカー案件の呼び水になる。
7. **ビフォーアフター**
   同じ食材を素人盛り→プロ盛りで比較。1秒で価値が伝わる。

### 最初の1秒の作り方

- 「今日は◯◯を作ります」は禁止。**完成形・音・否定形**から入る。
  - 悪い例:「今日は鶏のソテーを作ります」
  - 良い例: 皮がパリッと鳴る音 → 字幕「この音が出ないなら火が弱い」
- テキストは画面上部1/3に置かない（UIで隠れる）。

### 判定基準（5週間後）

- 平均リーチ 1,000 超え → 型が見つかっている。Phase 2 へ
- 平均リーチ 300 以下 → **本数ではなく冒頭1秒とテーマ設定を作り直す**

## 3. Phase 2（6〜11週）｜300 → 600：勝ち筋を増やしつつ、依頼の種を蒔く

### 増幅する

- **伸びた投稿の続編を5本作る。** 新ネタ探しより横展開のほうが期待値が高い。
- **投稿後1時間のコメント全返信。** 初速のエンゲージメントが配信量を決める。
- **ストーリーズを毎日1本。** 仕込み中・賄い・失敗など、完成品でなくてよい。
  料理人の日常は、それ自体が他の人には見えない資産。
- **質問スタンプで「今困っている料理」を集める** → そのまま次のリールのネタになる。
  ネタ切れの構造的な解決策。

### 依頼につなげる（この段階から並行）

- **月1本は「仕事の見せ方」の投稿を入れる。**
  依頼で作った料理、開発したレシピ、監修した内容（公開可能な範囲で）。
  「依頼できる人だ」と認識されない限り、依頼は来ない。
- **コラボ**: 同規模（500〜3,000人）の食品系アカウント、生産者、器の作家との共同投稿。
  相手のフォロワーにそのまま配信されるため、この段階で最も費用対効果が高い。
  月2件を目標に、具体的な企画をDMで持ちかける。
- **生産者・メーカーのタグ付け**: 使った食材の生産者を投稿でタグ付けする。
  リポストされればリーチが増え、かつ **そこから直接依頼が来る導線** になる。
  料理人の案件は、フォロワーからではなく「取引先の目に留まって」発生することが多い。

---

## 4. Phase 3（12〜20週）｜600 → 1,000：仕組み化と受注

- **曜日フォーマットの固定**: 例 火=技術、木=家庭再現、土=失敗解説。
  型が決まると制作が1本30分まで下がる。
- **バッチ撮影**: 週1日、仕込みのついでに3〜4本分をまとめて撮る。
  毎日ゼロから作ろうとすると3週間で止まる。
- **過去の当たり投稿を3か月後に作り直す。** フォロワーの大半は初見。
- **KPIをフォロワー数から切り替える**:
  1,000人に到達したら、追うのは「月間のDM問い合わせ件数」と「保存率」。

## 6. 数値管理

毎週この5項目だけ記録する。多すぎると続かない。

| 週 | 投稿数 | 平均リーチ | 保存率 | プロフ アクセス | フォロワー増 | DM問合せ |
|---|---|---|---|---|---|---|
| W1 | | | | | | |
| W2 | | | | | | |

### 見るべき比率と切り分け

- **保存率 = 保存数 ÷ リーチ**: 1%以上で良好、2%超なら伸びる
- **フォロー転換率 = フォロワー増 ÷ リーチ**: 1%未満ならプロフィールの問題

問題は必ずこの順で切り分ける。

- リーチが低い → **冒頭1秒**の問題（テーマではない）
- リーチはあるがフォローされない → **プロフィール**の問題
- フォロワーは増えるが依頼が来ない → **提供メニューと依頼導線**の問題

## 7. やってはいけないこと

- **フォロワーの購入・相互フォロー・フォロー&アンフォロー**
  エンゲージメント率が壊れ、以後のリーチが落ちる。
  そして案件目的では致命的で、**発注側はエンゲージメント率を見るため、
  数字だけ大きく反応が薄いアカウントは「買っている」と判断されて逆効果**になる。
- **PR表記の省略**
  2023年10月から、広告であることを隠すのは景表法違反（措置命令の対象）。
  提供を受けた食材・器具の投稿には必ず `#PR` を明記する。
  一度でも指摘されると、企業は二度と発注できない。
- **他人の写真・動画の無断使用**、他店の料理を自作のように見せること。
- **勤務先の許可を取らない店内撮影**。厨房・仕入れ先が映る場合は事前確認。

## 8. 最初の7日間

1. プロフィール5要素を書き換える（特に **提供メニュー** と **依頼導線**）
2. 依頼用のGoogleフォーム（または1枚ページ）を作り、リンクに設定する
3. ハイライト4本を作る ← 実績が少なくても「ご依頼について」は先に置く
4. 発信テーマを「店の技術を家庭で再現する」に固定する
5. 上の型リストから10本分のネタを書き出す
6. 火曜に仕込みのついでで4本撮る
7. 今週の4本を予約設定する

**最初の1本は「プロの手元」を無言で撮ったものにする。** 最も当たりやすく、
かつ技術の証拠としてハイライトにもポートフォリオにも使い回せる。
