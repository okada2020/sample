## 写真について

`photo_graded.jpg` は元の写真に次の処理をしたもの。

1. 黄色いコンテナ・ピザ・右側の雑然とした背景を外すトリミング
2. 頭が切れて写っていたため、前掛けと手元だけの構図へ変更
3. 青かぶりを除いて暖色へ（ホワイトバランス）
4. 黒を締め、白飛びを抑えるトーンカーブ
5. 彩度を2割落として、墨・生成り・真鍮の3色に馴染ませる
6. 周辺光量を落として視線を中央へ

**顔出しはしない方針のため、この構図（前掛けと手元）で正しい。**
元画像は目の高さで切れていて顔が入っていないが、今回はそれで問題ない。
ただし元が低解像度なので、下の条件で撮り直すと仕上がりが上がる。

## 撮り直しガイド（顔を出さない前提）

### 構図
- **縦（9:16）で撮る。** 横向きだと、文字を置く下の余白が足りなくなる
- 狙うのは次の3つ。**①が最も強い**
  1. **手元のアップ** — 包丁さばき、火入れ、盛り付け。技術がそのまま写る
  2. 前掛けと腕（今と同じ構図）。ただし手は必ず動かしている状態で
  3. 後ろ姿・俯瞰。厨房で作業している引きの画
- 顔が入らないよう、**胸から下**か**手元だけ**でフレームを切る
- 被写体は画面の**上から2/3**まで。下は空けておく（そこに文字が乗る）

### 光
- 手元に光が当たる向きで撮る。窓や照明を**正面〜斜め45度**に
- 真上の蛍光灯だけだと、手の影が料理に落ちて汚くなる
- ストロボの直射は使わない

### 背景
- 厨房でよい。ただし**雑然としたものが入らない角度**を選ぶ
- 具体的に外すもの：色の強いコンテナ、段ボール、貼り紙、ゴミ箱、私物
- 背景は暗いほうが、手元と料理が前に出る

### 撮り方
- 三脚（なければ台の上にスマホを固定）＋セルフタイマー。人手はいらない
- 服装は白シャツ＋黒エプロンで正解。変えなくてよい
- **同じ構図で10枚以上撮る。** 1枚だけだと必ず微妙なものしか残らない
- 美肌モードと広角は使わない

### 差し替え
撮った写真を `photo.jpg` として同じフォルダに置き、`highlight-slides.html` の
①のセクションを書き換えて書き出し直す。

```html
<section class="slide dark solo" id="t1" style="--photo:url('photo.jpg')">
```

ハイライトは後から差し替えできる（該当のストーリーズをハイライトから削除し、
新しいものを追加する）ので、**今の3枚を先に公開してしまってよい**。

## 編集のしかた

`highlight-slides.html` をブラウザで開き、文字はHTMLを直接書き換える。
写真は①のセクションの `--photo` を差し替える。

```html
<section class="slide dark solo" id="t1" style="--photo:url('photo_graded.jpg')">
```

書き出しは各スライドをスクリーンショット、または印刷→PDF。

## デザインの決めごと

- 上260px / 下300px は**ストーリーズUIの安全域**。文字を置かない
- 見出し＝明朝（Shippori Mincho）／本文＝ゴシック（Zen Kaku Gothic New）の2書体のみ
- 色は 墨 `#15120E` / 生成り `#F3EEE4` / 真鍮 `#C0914A` の3色のみ
- 1枚につきメッセージは1つ。詰め込まない
