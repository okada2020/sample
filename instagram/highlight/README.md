# 「はじめまして」ハイライト素材

Instagram ストーリーズ用 1080×1920。ハイライトに載せて使う。

**基本は `0_1mai.png` の1枚だけでよい。** 1枚で自己紹介が完結する。
以降の6枚は、じっくり見せたい場合の分割版（使わなくてよい）。

## 載せかた

1. `0_1mai.png` をストーリーズに投稿する
2. 投稿後、そのストーリーズを新規ハイライトに追加する
3. ハイライトのカバーに `7_cover_kinari.png`（または `7_cover_sumi.png`）を設定
4. ハイライト名は「はじめまして」

分割版を使う場合のみ、`2_keireki.png` の「◯年」に実際の年数を入れる。

## 写真について

`photo_graded.jpg` は、元の写真に次の処理をしたもの。

1. 黄色いコンテナ・ピザ・右側の雑然とした背景を外すトリミング
2. 頭が切れて写っていたため、前掛けと手元だけの構図へ変更
3. 青かぶりを除いて暖色へ（ホワイトバランス）
4. 黒を締め、白飛びを抑えるトーンカーブ
5. 彩度を2割落として、墨・生成り・真鍮の3色に馴染ませる
6. 周辺光量を落として視線を中央へ

元が低解像度なので、**顔が写った写真を撮り直して差し替えるのが望ましい**。

## 編集のしかた

`highlight-slides.html` をブラウザで開き、文字はHTMLを直接書き換える。
写真は2枚目のセクションの `--photo` を差し替える。

```html
<section class="slide dark bleed" id="s2" style="--photo:url('photo_graded.jpg')">
```

書き出しは各スライドをスクリーンショット、または印刷→PDF。
1080×1920 で切り出せば、そのままストーリーズに投稿できる。

## デザインの決めごと

- 上260px / 下300px は**ストーリーズUIの安全域**。文字を置かない
- 見出し＝明朝（Shippori Mincho）／本文＝ゴシック（Zen Kaku Gothic New）の2書体のみ
- 色は 墨 `#15120E` / 生成り `#F3EEE4` / 真鍮 `#C0914A` の3色のみ
- 1枚につきメッセージは1つ。詰め込まない
