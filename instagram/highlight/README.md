Instagram ストーリーズ用 1080×1920。ハイライトに載せて使う。

## 載せかた

1. `3mai_1` → `3mai_2` → `3mai_3` の順にストーリーズへ投稿する
2. 3件とも新規ハイライトに追加する（**順番が入れ替わらないよう投稿順のまま追加**）
3. ハイライトのカバーに `7_cover_B.png` を設定する
4. ハイライト名は「はじめまして」

## 3枚の役割

| 枚 | 見る人が受け取るもの |
|---|---|
| ① | 誰なのか（コックコート・屋号・経歴） |
| ② | フォローすると何が流れてくるのか |
| ③ | この人に何を頼めるのか |

**②が「フォローする理由」、③が「依頼が来る導線」。** どちらも外さない。

## 写真について

`photo_chef.jpg` は、スタジオ撮影のポートレートに次の処理をしたもの。

1. **顎より下でトリミング。** 顔はフレーム外。首の途中から下端まで
2. コックコートと組んだ手が主役になる構図に調整
3. 背景の青かぶりを選択的に除去し、生成りに寄せた暖色ニュートラルへ
   （肌は R が大きく上回るためマスクで除外し、背景だけを補正）
4. 黒を締め、ハイライトのロールオフで白飛びを防止
5. 彩度を8%落として、墨・生成り・真鍮の3色に馴染ませる

**顔を出さずに「料理人である」ことが一目で伝わる素材になっている。**
コックコートと組んだ手が、顔の代わりに職業と清潔感を担っている。

## 編集のしかた

`highlight-slides.html` をブラウザで開き、文字はHTMLを直接書き換える。
写真は①のセクションの `--photo` を差し替える。

```html
<section class="slide light solo" id="t1" style="--photo:url('photo_chef.jpg')">
```

書き出しは各スライドをスクリーンショット、または印刷→PDF。

## デザインの決めごと

- 上260px / 下300px は**ストーリーズUIの安全域**。文字を置かない
- 見出し＝明朝（Shippori Mincho）／本文＝ゴシック（Zen Kaku Gothic New）の2書体のみ
- 色は 墨 `#15120E` / 生成り `#F3EEE4` / 真鍮 `#C0914A` の3色のみ
- 1枚につきメッセージは1つ。詰め込まない
