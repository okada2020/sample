## ⚠️ 投稿前に埋める箇所

`irai_2_joken.png` の4項目がすべて `◯` のままになっている。

| 項目 | 入れるもの |
|---|---|
| 人数 | `◯〜◯名さま` |
| 時間 | `約◯時間` |
| エリア | `◯◯市内および近郊` |
| 料金 | `お一人 ◯,◯◯◯円〜` |

**料金は「応相談」にしない。** 法人は予算が組めず候補から外す。
幅でよいので数字を出しておけば、後から調整できる。

## デザインの方針（第1案からの変更点）

第1案（墨 × 明朝 × 真鍮）は**フィードと合わず却下**された。
この「ご依頼」は方針を変えている。

| | 第1案（却下） | この案 |
|---|---|---|
| 背景 | 墨 `#15120E` | **ほぼ白 `#FBF9F5`** |
| 書体 | 明朝（高級店の語彙） | **角ゴシックのみ** |
| 色 | 真鍮のアクセント | **色を使わない**（濃淡と太さだけで階層を作る） |
| 印象 | 静か・高級 | **明るい・清潔・読みやすい** |

フィードの料理写真が明るく清潔なトーンなので、それに合わせてある。

## 編集のしかた

`request-slides.html` をブラウザで開き、HTMLを直接書き換える。
各セクションをスクリーンショットすれば1080×1920で書き出せる。

- 上260px / 下300px は**ストーリーズUIの安全域**。文字を置かない
- 色は背景 `#FBF9F5` / 文字 `#26221E` / 補助 `rgba(38,34,30,.56)` / 罫 `rgba(38,34,30,.13)` の4つだけ

## カバー

このハイライトのカバーだけは料理写真でなくてよい。
**配膳した卓の引きの絵**か、料金を書いたカードを撮ったものが合う。
`../cover-proposals/cover-builder.html` で書き出す。
