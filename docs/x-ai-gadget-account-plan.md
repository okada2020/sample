作成日: 2026-08-23

## 0. 結論

**「AIガジェットの検証屋」** として立ち上げます。ガジェット全般ではなく **AIデバイスに絞る**。

理由は3つ。

1. **2026年はスマートグラス元年**。Meta / Google×Samsung / XREAL / VITURE / Even / HTC VIVE / 国産SABERA と新製品が一斉に出ており、**まだレビューの母数が少ない波**が来ている。
2. **AI・テック・ガジェットはいずれも広告主のCPMが高い**ジャンル。3つの高単価領域が重なる位置に立てる。
3. ガジェット全般は競合が非常に多く後発が埋もれるが、「AIデバイスの人」なら**アルゴリズムのジャンル分類でも一意に認識される**。

> 前回の比較表でガジェットを △ としたのは **実機コスト**が理由でした。これは「4. 実機ゼロ〜1台で回す設計」で潰します。

## 1. ポジショニングと差別化

### 競合の現状

| タイプ | 代表例 | 強み | 後発が勝てるか |
| --- | --- | --- | --- |
| セール速報 | @gadgetsale_info（**プログラムで前日比10%以上の値下げを自動投稿**） | 速度・網羅性 | ✕ 人力では不可能 |
| ニュース配信 | @daily_gadget_jp | 情報量・更新頻度 | ✕ 体力勝負 |
| 実機レビュー | TikGadget など | 写真・実測データ | △ 機材コスト次第 |
| **AI特化の検証** | 手薄 | ─ | **○ ここを取る** |

### 取るポジション

**「そのAIガジェット、実際どこまで使えるのか」を検証する人。**

- スペック紹介ではなく **使用シーンでの合否判定**をする（例：翻訳グラスは会議で実用に耐えるか）
- 「買うな」も言う。**中立性が信頼＝購買につながる**唯一の資産
- ネタ元は最新機種に限定しない。**手持ちのスマホ／PC＋AIアプリ**も立派なAIガジェット

### ターゲット

- **主軸**：AIに興味はあるがデバイスは未購入の20〜40代（拡散する層）
- **収益側**：3〜10万円のガジェットを検討中の購買層（アフィリエイトが成立する層）

## 2. 投稿の4本柱

週14〜20投稿を、この4つだけで回します。

### ① 検証・合否判定（週3〜4）★最重要

実際に使って、**結論を先に出す**。

```
スマートグラスの同時通訳、会議で使えるか試した

結論：1対1の雑談は合格、複数人の会議は無理

・遅延 約1.5秒 → 相槌のタイミングがズレる
・複数人が被ると話者を取り違える
・単語単位の誤訳は文脈で補える範囲

「翻訳できる」と「会議で使える」は別物だった
```
- 画像：使用中の写真 or 画面キャプチャ1枚（ALT必須）
- 型：**知識 ＋ 意外性**

### ② 比較・選び方（週3〜4）

**保存（ブックマーク）される型**。実機不要で作れる。

```
AIスマートグラス、用途別の正解（2026年8月版）

・AIアシスタント重視 → Meta Ray-Ban
・文字で情報を見たい → Even G2
・映像を大画面で見たい → XREAL / VITURE
・Androidと深く繋ぎたい → Google×Samsung（今年後半）

「全部入り」はまだ存在しない。用途を1つ決めてから選ぶ
```
- 画像：比較表を1枚画像に（**ここで制作スキルが活きる**）
- 型：**まとめ**

### ③ AI活用の実演（週3〜4）

手持ち機材だけで成立し、**AI文脈のジャンル分類を強化**する柱。

```
音声メモを議事録にするやつ、結局これが一番速かった

録音 → 文字起こし → 要約まで 40秒

（30秒の画面録画）
```
- 縦型動画30〜60秒。プロセスを見せる
- 型：**知識**

### ④ 意見・業界の見立て（週1〜2）

会話を発生させる柱。返信が往復すると再拡散されます。

```
スマートグラスが売れない理由、性能じゃなくて「見た目」だと思ってる

技術的には去年の時点で十分実用域だった
でも街で掛けられるデザインになったのは今年から

普及のボトルネックはいつも技術じゃない
```
- 型：**意見表明 ＋ 共感**

## 3. 投稿の実務ルール

- 本文に**リンクを貼らない**（リーチ50〜90%減）。リンクは**リプライに置く**
- ハッシュタグは0〜1個。2026年はほぼ効果なし
- 画像には**必ずALTテキスト**（画像認識AIがスコアに直結）
- 冒頭1行に**結論**を置く。「結論：」「〜は無理だった」など
- 1日3〜5投稿。量産より質
- 投稿後30〜60分は返信に全部返す（会話の継続＝再拡散）
- 数字を必ず入れる（遅延1.5秒、40秒、2万円差）。検証系は**数値が説得力そのもの**

## 4. 実機ゼロ〜1台で回す設計

**最初の1〜2か月は実機を買わずに立ち上げます。**

| 月 | 実機投資 | 投稿の主軸 |
| --- | --- | --- |
| 1か月目 | **0円** | ②比較・選び方 ＋ ③手持ち機材でのAI活用実演 |
| 2か月目 | 0円 | 同上＋④意見。反応の良いカテゴリを特定する |
| 3か月目 | **1台だけ購入**（3〜5万円想定） | ①検証を開始。1台を10投稿以上に分解する |

**1台を使い倒す分解例**：開封／1週間使用レビュー／バッテリー実測／競合との比較／こういう人は買うな／3か月後の再レビュー／付属アプリ検証／ケース・周辺機器

購入判断は **2か月目の実測データ**で決めます。②③で反応が最も良かったカテゴリの機種を買う。先に買わない。

## 5. 収益設計

### 収益の3段構え

| 収益源 | 立ち上がり | 見込み | 備考 |
| --- | --- | --- | --- |
| X広告分配 | 遅い | 低〜中 | AI・テックはCPMが高いジャンル。ただし本命ではない |
| **アフィリエイト** | 中 | **中** | 家電・カメラの紹介料率は **2〜3%** が中心 |
| 企業案件・レビュー依頼 | 遅い | 高 | フォロワーの「質」で決まる。**ここが本命** |

**規模感の目安**：一般にフォロワー5〜10万が目安とされるが、**購買意欲の高い1万人**でも月数万円は成立する。数より濃さを取る。

### アフィリエイトの実務（重要）

- **Amazonアソシエイトは X 単体では通常審査を受けられない**。ブログ／サイトで登録し、**Xアカウントの URL を登録サイトとして必ず申請**する（未申請だと規約違反になり得る）
- 審査通過には申請後 **180日以内に3件以上の売上**が必要
- **2026年4月の規約変更**：X のプロモーション投稿（有料広告）から Amazon リンクへ直接誘導するのは違反の可能性。**通常投稿からの紹介は従来どおり可**
- リンクの貼りすぎはスパム判定を招く。**自然な紹介の中に置く**
- 王道の導線は「他SNSやコンテンツで認知 → X とプロフィールリンクで購買」。**ブログ or note を1つ持つと Amazon 審査・回遊の両方で有利**

### ステマ規制（必ず守る）

2023年10月から、ステマは景品表示法上の**不当表示として規制対象**。**2026年現在も消費者庁の執行は活発**です。

- 対価（報酬・商品提供・貸与）が発生した投稿は、**「PR」「広告」を消費者が分かる形で明示**する
- 「アフィリエイトリンクを含みます」の一文をリプライのリンクと同じ位置に置く
- **提供品のレビューでも忖度しない**。中立性がこのアカウントの資産

## 6. コーディングスキルの活かしどころ

競合の @gadgetsale_info が**プログラムで価格を監視して自動投稿**しているように、この領域は**技術がそのまま差になります**。

- **価格監視スクリプト**：ウォッチ対象のAIガジェットの値動きを取得し、**下がったら自分に通知**（投稿は手動で判断を添える）
- **比較表の自動生成**：スペックをJSONで持ち、HTML/CSSで整形して画像化。②の柱の制作コストがほぼゼロになる
- **投稿ストック管理**：ネタ・下書き・投稿済みをリポジトリで管理

⚠️ ただし **全自動投稿はスパム判定・凍結のリスク**があります。**収集は自動化し、投稿は人の判断を通す**。この線は守ってください。

## 7. アカウント初期設定

**プロフィール文案**

```
AIガジェットを実際に使って合否を出す人｜スマートグラス・AIデバイスを
「買っていいか」の視点で検証／スペックより使用シーン重視／忖度なし
```

**固定ポスト**：最初は「このアカウントで検証していく機種リスト」を1枚画像で。伸びた投稿が出たらそれに差し替える。

**ヘッダー**：検証中の画がある写真、なければ「用途別の選び方」比較表をそのまま使う。

## 8. 30日ロードマップ

| 期間 | やること |
| --- | --- |
| Day 1–3 | アカウント作成・プロフィール整備。同ジャンル50アカウントをフォローして観察。**この期間は投稿を量産しない**（新規アカの大量投稿は凍結リスク） |
| Day 4–14 | 1日2〜3投稿。**②比較 ＋ ③AI実演**のみ。型ごとの反応を測る。返信は全部返す |
| Day 15–21 | 反応の良い型に寄せて1日3〜5投稿へ。**縦型動画を週2**追加。ブログ/note を1本立ててAmazonアソシエイト申請 |
| Day 22–30 | 伸びた投稿を比較表・スレッドに再編集。固定ポストを最も伸びた投稿に差し替え。**購入する1台を決定** |

**30日後に見る指標**（フォロワー数ではなく）
1. **ブックマーク数** — 比較・まとめが刺さっているか
2. **プロフィールクリック率** — 興味を持たれているか
3. **非フォロワーからのインプレッション比率** — ジャンル分類が効いているか

この3つが伸びていれば、フォロワーは後からついてきます。

## 9. 複数アカウント運用の遵守事項（再掲）

- **サブ垢でメインの投稿を拡散しない**（相互いいね・RT は規約違反）
- **同一・類似コンテンツを複数アカウントで投稿しない** → 既存アカウントと**投稿内容を明確に分ける**
- 凍結歴のある電話番号・メールアドレスは使い回さない
- 作成直後の大量フォロー・大量投稿を避ける
