# X（旧Twitter）2アカウント目リサーチ ─ どんな投稿に需要があるか

作成日: 2026-08-23

---

## 0. 前提

- このリポジトリの中身（病院サイト・洋菓子店サイトの制作物）から、**運用者はWeb制作／コーディングのスキルを持つ**と想定してジャンル候補を組み立てています。
- 既存アカウントのジャンルが別領域の場合は「6. 候補ジャンル比較表」から選び直してください。判断材料はそのまま使えます。

**結論（先に3行）**

1. 2026年のXは「フォロワー数」ではなく **初速の反応 ×滞在時間 ×ジャンルの一貫性** で配信量が決まる。だから2アカ目は**1テーマに絞る**のが最重要。
2. 需要（インプレッション）と収益単価が両立するのは **AI・テック・ビジネス・投資・ガジェット** 系。制作スキルと接続できる。
3. 推奨は **「Web制作 × AI実演」を軸に、Before / After が一目でわかるビジュアル投稿**。保存（ブックマーク）されやすく、そのまま案件獲得の導線になる。

## 2. 2026年のアルゴリズム（何が伸びるかの前提条件）

### 効く要素

- **初速のエンゲージメント**：投稿後の反応が薄いと数時間で完全にタイムラインから消える。フォロワー数は以前ほど効かない。
- **滞在時間**：スクロールを止めて読ませた・見せた時間がスコアになる。
- **マルチアクション予測**：2026年5月のアップデートで、AI が1投稿に対し **いいね／RT／ブックマーク／返信など12種類の行動が起きる確率を同時に予測**するモデルへ移行。「なんとなくバズる」が成立しにくくなった。
- **ジャンル分類**：AI がアカウントを「経済」「AI」「恋愛」などに分類。**軸がはっきりしているほど専門家として認識**され、非フォロワーの興味関心層に配信される。逆に「何でも屋」は分類できず**ノイズ判定**で誰にも届かない。
- **会話の継続**：スレッド内で返信が往復すると「まだ生きている投稿」と判定され、再拡散される。
- **ALTテキスト**：画像認識AIの解析結果がスコアリングに直接組み込まれたため、**代替テキストの記入が実質的なランキング要素**になった。
- **リッチメディア**：画像・動画・GIF付きは注目されやすい。特に縦型動画は「おすすめ」欄の露出を取りやすい。
- ただし X は **テキストが動画に勝つ唯一の主要SNS**でもある。動画一辺倒にせず、文章 × 図解の組み合わせが強い。

### ペナルティ・効かない要素

- **外部リンク**：本文にリンクを入れるとリーチが **50〜90% 減**。→ リンクは**リプライ（ツリー2件目）に置く**のが定石。
- **ハッシュタグ**：2026年はほぼ無意味。アルゴリズムは自然言語処理で意味を理解して分類するため、タグ依存は不要（むしろ可読性を落とす）。
- **量産**：低品質を10回より、**質の高い投稿を1日3〜5回**のほうが伸びる。

### 文字数の目安

英語圏データでは短文（71〜100字）が +17% エンゲージメント、上限近く（240〜259字）はいいね数が最多。**日本語ではおよそ半分の体感**で、
- 単発ポスト：**60〜120文字**（スマホ2〜3行で読み切れる）
- ノウハウ系：**画像に情報を寄せて本文は短く**

## 3. 「バズる」の基準と再現性のある5つの型

**バズの目安**：インプレッション **10万超** または リポスト **1,300件超**。

再現性が高い5つの型：

| 型 | 中身 | Web制作アカウントでの例 |
| --- | --- | --- |
| **知識** | 知らないと損する具体ノウハウ | 「`text-wrap: balance;` 1行で見出しの改行位置が整う」 |
| **共感** | あるあるの言語化 | 「クライアントの『なんかイマイチ』が一番きつい」 |
| **意外性** | 常識が覆る事実 | 「ハッシュタグはもう効かない、ALTテキストのほうが効く」 |
| **意見表明** | 立場を明確にする | 「AIでコードは書けても、要件の切り分けは代われない」 |
| **まとめ** | 保存前提の一覧 | 「無料で使える日本語Webフォント12選（画像1枚）」 |

**投稿の作り方の手順**：型を選ぶ → 冒頭フックを作る → 画像・図解を用意する → 時間帯を選ぶ → 初動をつくる（返信・引用で会話を起こす）。

**スレッドの使い方**：スレッドは各ポストが個別にいいね・RT・ブックマークされるため、価値の高い1枚や結論をツリーの途中に置くと、その1件だけで独立して伸びることがある。

## 4. 収益面：単価が高いジャンル

- 広告主が高CPMで出稿するのは **AI・テック・金融・投資・不動産・ビジネス・ガジェット**。クリエイター側の分配単価もここが高い。
- 参考：X広告のCPM相場は **500〜1,500円／1,000インプレッション**（広告主が払う額。分配はこの一部）。
- **重要**：広告分配（インプレ収益）だけを狙うのは効率が悪い。専門性のある発信でコミュニティを作り、**有料コンテンツ・受注に流したほうが収益は安定する**というのが2026年の共通見解。
- **ジャンルの乗り換えは非推奨**。知識が浅くなり投稿が薄くなる。今の発信の延長線上で高単価ジャンルとの接点を探すのが確実。
  → Web制作 × **AI** は、まさにその「延長線上の高単価接点」に当たる。

参考トレンド：「副業（side hustles）2026」の検索は直近四半期で **約48%増**、世界で月間約6万件。AI副業文脈は需要が拡大中。

## 5. 推奨する2アカウント目の設計（本命案）

### コンセプト：「AIと一緒にサイトを直す人」

既存の制作スキル × 高単価ジャンル（AI／テック）× ビジュアルで完結、の交点。

**ターゲット**：①独学中〜駆け出しのWeb制作者（拡散してくれる層）／②自社サイトに不満がある中小事業者（発注する層）

**投稿の柱（この4つだけを回す）**

1. **Before / After 診断**（週2）
   実在しない架空サイト or 自作サンプル（この repo の病院サイト・洋菓子店サイトが素材としてそのまま使える）を「ダサい状態 → 直した状態」で1枚に並べる。
   *フック例*：「病院のサイト、この3か所直すだけで信頼感が別物になる」
2. **AI実演**（週2）
   AIにコードを書かせる／レビューさせる過程を **30〜60秒の縦型画面録画**で。プロンプトも公開する。
   *フック例*：「『ここもう少し余白』を実際のCSSに翻訳させたらこうなった」
3. **1行Tips / 図解まとめ**（週2〜3）
   CSSの小技、ALT・アクセシビリティ、フォント選び。**保存される＝ブックマーク**を狙う型。
4. **意見・現場の実感**（週1〜2）
   AI時代の制作単価、独学ロードマップへの意見など。共感・議論で会話を発生させる。

**なぜこの設計か**

- Before / After は **スクロールを止める＝滞在時間**を稼げる。画像1枚で成立し、制作コストが低い。
- AI文脈に乗るため **CPMの高いジャンル分類**に入りやすい。
- 見た人がそのまま **発注者になりうる**（インプレ収益より確実な収益導線）。
- リポジトリの既存制作物が素材として無限に使えるので、ネタ切れしにくい。

### 対抗案（比較のため）

- **案B：中小事業者向け「ホームページ改善」特化** — 競合が薄く受注に直結するが、拡散力（インプレ）は伸びにくい。受注目的なら最短。
- **案C：AI／ガジェット／投資など制作と無関係な高単価ジャンル** — 単価は最高だが、専門性ゼロからは投稿が薄くなりやすく、上記「乗り換え非推奨」に該当。おすすめしない。

## 7. 運用ルール（実務チェックリスト）

- [ ] 投稿は **1日3〜5回**。量より質。
- [ ] **本文にリンクを貼らない**。リンクはリプライに置く。
- [ ] **ハッシュタグは0〜1個**。基本不要。
- [ ] 画像には **必ずALTテキスト**を入れる（画像認識AI＋アクセシビリティ両取り）。
- [ ] 冒頭1行で内容が伝わるフックを作る（続きを読む位置より前に結論）。
- [ ] 投稿後30〜60分は張り付いて **返信に全部返す**（会話の継続＝再拡散）。
- [ ] 同ジャンルの発信者に自分から絡む（初速の反応を作る唯一の現実的な手段）。
- [ ] 週1で数字を見る：伸びた投稿の「型」を記録し、当たった型を再生産する。
- [ ] プロフィール・固定ポスト・ヘッダーで「誰の何を解決する人か」を1行で言い切る。

**投稿時間の考え方**：ターゲットが「没入型」なら夜（21〜23時）、「隙間型」なら朝の通勤帯（7〜9時）と昼休み（12時台）。まず両方試して自分のアカウントの当たり時間を実測する。

## 8. 複数アカウント運用の注意（凍結回避）

Xの規約・運用実態から、**必ず守る**べき点：

- 明示的な上限は公表されていないが、**用途の異なるアカウントを最大10個程度**が実運用上の線。管理しやすいのは2〜5個。
- **禁止行為**：
  - サブアカウントでメインの投稿を拡散する（相互いいね・相互RT）
  - トレンドの操作を狙った複数アカウント運用
  - **同一または実質的に類似のコンテンツを複数アカウントで投稿する**
- → つまり **2アカ目は「メインと投稿内容・用途をはっきり分ける」ことが規約上も必須**。今回の設計（テーマを1つに絞る）はこの要件も同時に満たす。
- 過去に凍結されたアカウントの **電話番号・メールアドレスは絶対に使い回さない**（連鎖凍結の原因）。
- 作成直後に大量フォロー・大量投稿をしない。数日かけて自然に立ち上げる。

## 9. 最初の30日ロードマップ

| 期間 | やること |
| --- | --- |
| Day 1–3 | アカウント作成、プロフィール／ヘッダー／固定ポスト作成。まだ投稿を量産しない。同ジャンルのアカウントを50前後フォローして観察 |
| Day 4–14 | 1日2〜3投稿。「Before/After」「1行Tips」を中心に、**型ごとの反応を測る**。返信は全部返す |
| Day 15–21 | 反応の良かった型に寄せて1日3〜5投稿へ。**縦型動画のAI実演**を週2で追加 |
| Day 22–30 | 伸びた投稿をスレッド化・図解化して再利用。固定ポストを「一番伸びた投稿」に差し替え。問い合わせ導線（リプライにリンク）を設置 |

**30日後に見る指標**：フォロワー数ではなく、①ブックマーク数 ②プロフィールクリック率 ③非フォロワーからのインプレッション比率。この3つが伸びていればジャンル分類が正しく効いている。
