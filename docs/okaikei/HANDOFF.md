## 企画

24時間営業のスーパー、深夜1:20。主人公は手持ちカゴで買い物し、セルフレジで支払い画面に「お支払い金額 47.2kg円」が出て、台の下から赤い液体が流れ出す。背後で物音がして振り向くと誰もいない。向き直ると血も消え、金額も正常に戻っている。何事もなかったように会計を済ませると、レシートに「後ろを見ないでください」。防犯カメラに戻ると主人公は一人だが、体重センサーは 47.2kg → 94.4kg。

参照した文法（8番出口 / Chilla's Art）：先に「普通」を見せる、異変は小さく1つで指ささない、カメラは反応しない、BGMなし環境音のみ、記録映像の質感、怪物は出さない。

追加の決定事項：
- 血は**復活**（前の「一滴垂れて残る」ではなく、**台の下から流れて、消える**）。消えるなら異変であってゴアではない

## 学んだこと（同じ失敗をしない）

- 静止画→動画の順。文字のある画面は静止画モデルに描かせ、動画では「変えない」と指示
- カメラを「前進させない」と明示しないと、見上げる動きで歩き出す
- 動かない人影は、静止画を開始／終了フレームに固定してしか保証できない
- 参照画像の系譜に注意。自分の生成物を参照にし続けると、最初の崩れ（カゴ、棚）が全カットに広がる。根元は依頼者の実写風静止画に戻す
- Seedance のプリセット提案「IN THE DARK」（`24bae836-2c4a-48e0-89b6-49fcc0b21612`）は断って `declined_preset_id` で再送
- Claude のコンテナから Higgsfield の CDN は見えない。`media_import_url` → `video_analysis_create` で文章として確認する。解析は日本語を読まないので、文字の確認は依頼者に頼む
- クレジット：開始 453.94 → 2026-09-20 時点で約147。動画は 480p（12）を使う
