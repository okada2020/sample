# セルフレジホラーCM — 制作工程メモ

『お会計』で確立した作り方。**次の作品でもそのまま使える手順**として書いてある。プロジェクトの進捗状況は `HANDOFF.md`、この文書は「どう作るか」。

---

## 全体の流れ

```
① 企画（何が怖いかを1行で）
② 参照研究（同ジャンルの文法を抜き出す）
③ 絵コンテ（文章。カット番号・秒数・カメラ・演出メモ）
④ プリビズ（3Dブロッキング。カメラ位置と立ち位置を確定）
⑤ 静止画（1カット1枚。文字はここで作る）
⑥ 動画（静止画を開始/終了フレームに固定して動かす）
⑦ 確認（依頼者の目視 ＋ サーバー側の映像解析）
⑧ 編集（合成・つなぎ・グレード・音）← 依頼者側
```

**③④を飛ばすとクレジットが溶ける。** 『お会計』では構図を決めずに生成を始めたため、カゴ・棚・カメラの前進で7〜8本を無駄にした。

---

## ① 企画

**恐怖の源を1つに決めて、それ以外を全部禁止する。** 『お会計』は「日常の機械表示の異常」。だから怪物・暗闇・大きな音・ジャンプスケアは最初から禁止リストに入れた。

禁止リストを先に書くと、あとの判断が全部速くなる。

## ② 参照研究

同ジャンルの成功作を3〜5本調べて、**共通する「文法」を6つ以内**に圧縮する。『お会計』で抽出したもの（8番出口 / Chilla's Art / HELLMART）：

1. 先に「普通」を見せる。異変は普通との差分でしか成立しない
2. 異変は小さく1つ。**指ささない**（ズーム・効果音・音楽で教えない）
3. カメラは反応しない。主人公も驚かない。**反応の不在**が恐怖
4. 音は環境音のみ。BGMなし
5. 「撮影されたもの」でなく「記録されていたもの」（防犯カメラ、VHS、ニュース）
6. 怪物を出さない。出すとしても普通の人間の形

## ③ 絵コンテ

表で書く。**1行＝1カット**。列は `# / 内容 / 秒 / カメラ / 素材の状態`。

- 尺の配分：**「普通」に全体の4割**。30秒なら12秒、60秒なら25秒
- 異変が出たら**カットを切らずに2秒以上放置する**。視聴者が自分で画面を探す時間
- 各カットに「やらないこと」を書く（例：ズームしない、人を入れない、音を鳴らさない）

## ④ プリビズ

`previz` スキルで3Dブロッキングのページを作る。球体の頭＋棒の体、向き矢印、カットごとのカメラ。

ここで確定させるもの：**カメラの高さ・向き（yaw/pitch）・画角・被写体との距離・小道具の配置**。これが決まっていると、⑤のプロンプトが「フレームの説明」として書ける。

## ④.5 文字ものは生成しない ― ブラウザで描く

**これが一番大きい発見。** レジ画面・レシート・防犯カメラのオーバーレイ・タイトル・ニュースの枠は、全部「図形と文字」でできている。生成モデルに描かせる理由がない。

`docs/okaikei/assets/build.py` が HTML を書いて headless Chromium で PNG に書き出す。

- **日本語が絶対に崩れない**（IPAGothic がコンテナに入っている）
- **毎回まったく同じレイアウト**。47.2kg円 と 1,284円 が完全に一致するので「数字だけ変わった」が成立する
- **クレジットゼロ**、数秒で書き出せる、文言の変更は1行
- **Claude 自身が結果を見て確認できる**（Higgsfield の生成物は CDN がブロックされていて見られない）

透過PNGも出せるので、防犯カメラのオーバーレイはそのまま映像に重ねられる。

```
cd docs/okaikei/assets && python3 build.py   # out/*.png
```

生成モデルが要るのは**写真的なカット**（人・店内・手・光）だけ。文字が入る画面は、写真側を無地で作って、この PNG を合成する。

## ⑤ 静止画

**1カット1枚。文字は必ずここで作る。** 動画モデルは日本語を溶かすが、静止画モデル（`gpt_image_2_5`）は正確に描ける。

プロンプトの型：

```
Photorealistic first-person POV photograph, vertical 9:16,
[場所と時刻と光]
[画面を上中下の3バンドに分けて、それぞれ何があるか]
[手・袖・持ち物の指定]
[UI文字は「」で囲んで一字一句]
[異常は1つだけと明記]
No real brand logos. Natural smartphone-camera look, no film grain, no vignette.
Keep the image strictly first-person POV.
```

**縦9:16は上中下の3バンドで設計する。** 例：上＝画面、中＝カウンターと手、下＝床。1フレームに3つの情報が入り、どれも指ささずに済む。

### 連続性の作り方

同じ場所の別カットは、**前のカットの静止画を参照画像にして作る**。「Recreate the reference image EXACTLY — with only these changes: ...」と書き、変える点だけ列挙する。これで「同じ写真の数秒後」になる。

⚠️ **参照の系譜に注意。** 自分の生成物を参照にし続けると、最初の崩れが全カットに遺伝する。『お会計』ではカゴの形が5カットに広がった。**根元は実写（依頼者の撮影・撮影風の素材）に戻す。**

## ⑥ 動画

`seedance_2_5` の `omni_reference`。**480p / 4秒 = 12クレジット**（720p は28、1080p は48）。

鉄則：

- **1生成＝1視点・1動作・1カメラ移動。** 複数の動きを混ぜると順序が壊れる
- **開始フレームと終了フレームを両方固定する。** これが唯一の「確実に狙い通りに動かす」方法
- **「前進しない」を明示する。** 書かないと、見上げる指示でカメラが歩き出す
- **「画面の内容を変えない」を明示する。** 文字を動かすと溶ける
- **状態変化は「変化を映さない」。** 例：目を離した隙に血が消える → 終了フレームに「すでに消えた世界」を置き、`Do not animate the liquid fading` と書く
- プリセット提案（`preset_recommendation`）が返ったら断って `declined_preset_id` で再送

### 逆再生という手

対称な動き（振り向く↔戻る、見上げる↔見下ろす）は、**1本作って逆再生**すれば2本分になる。ただし**終了状態が違う場合は使えない**（『お会計』のC7は世界が変わるので別生成が必要だった）。

## ⑦ 確認

**Claude は Higgsfield の CDN を直接見られない**（組織のegressポリシーでブロック）。確認は2段構え。

1. **サーバー側の映像解析** — `media_import_url` → `video_analysis_create` → `video_analysis_status`。構図・カメラの動き・人物の有無・物の配置は文章で正確に返ってくる
2. **依頼者の目視** — 解析は**日本語を読まない**し、**指の破綻も拾わない**。文字と手は必ず人間が見る

だから Claude 側は「解析で分かること」を先に判定し、**依頼者には2〜3点だけ絞って聞く**。全部確認してもらうと止まる。

## ⑧ 編集（依頼者側）

1. **文字の合成** — 静止画の画面領域を動画にトラッキング合成。固定カメラのカットは特に簡単
2. **オーバーレイ** — 防犯カメラの REC・時刻・センサー表示
3. **グレード** — 全カットに同じ色調整（少し暗く、少し青緑）。これだけで8カットの統一感が出て、細かい色ズレも目立たなくなる
4. **音** — BGMなし。自動ドア、冷蔵庫、足音、カゴ、スキャン音、プリンター、蛍光灯のノイズ。異変の瞬間に**音を1つ消す**のが効く

## やりがちな失敗（実際にやった）

| 失敗 | 対策 |
|---|---|
| 完成動画を一発で作ろうとする | 1生成＝1動作に割る |
| 動画モデルに日本語を描かせる | 静止画で作って合成 |
| 「見上げる」と書いたらカメラが歩き出した | 「前進しない」を明示 |
| 動かないはずの人影が歩き去った | 開始/終了フレームを固定 |
| カゴの形が全カットで変 | 参照の根元を実写に戻す |
| 構図を決めずに生成を始めた | プリビズを先に作る |
| 異変を増やして怖くなくなりかけた | 恐怖ではなく「普通」を伸ばす |
