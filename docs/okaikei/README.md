# 『お会計』― セルフレジ・ホラーゲームのCM

縦9:16・約1分・日本語。AIで作ったホラーゲームのCMとして YouTube に出す。
**このフォルダだけで全部わかるようにしてある。**

## あらすじ

深夜23時20分、24時間スーパー。残業帰りの肉体労働者が、行方不明の女性のニュースを
スマホで見ながら歩いて入店する。カップ麺と半額の弁当と発泡酒と水を手持ちカゴで買う。
セルフレジの支払い画面が**「お支払い金額 47.2kg円」**になり、台の下から赤い液体が
流れ出す。背後で物音、振り向くと誰もいない。向き直ると血も金額も元に戻っている。
何事もなかったように会計を済ませると、レシートに**「後ろを見ないでください」**。
防犯カメラに戻ると彼は一人だが、体重センサーは **47.2kg → 94.4kg**。

**47.2kg は行方不明の女性の体重。** ただしニュースは体重を言わない。
「身長158センチくらい／小柄で痩せ型」としか言わないので、**視聴者が自分で繋ぐ**。

## 守ること

- **文字が入る画像は生成しない。** `assets/build.py` で描く（日本語が崩れず、クレジットゼロ）
- **動画は 480p。** 4秒=12クレジット（720pは28、1080pは48）
- 実在の企業・決済サービス・放送局の名称とロゴは出さない
- 怪物を出さない。異変は小さく1つだけ、指ささない、カメラも主人公も反応しない
- **主人公は特定させない。**顔ではなく「どういう男か」を分からなくする（設定シート参照）
