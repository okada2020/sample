# 文字もの素材 ― 生成モデルを使わずブラウザで描く

このフォルダだけで完結している。`build.py` が HTML を書いて headless Chromium で
PNG に書き出す。**日本語が崩れず、毎回まったく同じレイアウトで、クレジットはゼロ。**

```
python3 build.py     # out/*.png を全部書き直す
```

必要なもの：Python 3（標準ライブラリのみ）と Chromium か Chrome が PATH にあること。
日本語フォントは IPAGothic → Noto Sans CJK JP → Hiragino Sans の順に探すので、
mac ならそのまま動く。

## なぜ生成モデルを使わないか

レジ画面・レシート・防犯カメラのオーバーレイ・タイトル・ニュースの枠は、
**全部「図形と文字」**でできている。生成モデルに描かせる理由がない。むしろ：

- 生成モデルは日本語を溶かす
- 毎回レイアウトが変わる。`screen_47_2kg` と `screen_1284` が**ピクセル単位で同一**
  でないとこの映画の中心（目を離した隙に世界が戻る）が成立しない
- 1枚10クレジットかかる

**生成モデルが要るのは写真的なカットだけ**（人・店内・手・光）。文字が入る画面は、
写真側を無地で作っておいて、ここの PNG を合成する。

## 変えるならここ

- **`ASSETS`** が全出力の一覧。1行足せば1枚増える
- **金額**は `kiosk("47.2kg円")` の引数だけ。`screen_47_2kg` と `screen_1284` は
  数字以外まったく同じでなければならないので、**片方だけレイアウトを触らない**
- **体重**は `cctv(..., "47.2")` / `"94.4"` の引数
- **ニュースの中央映像**は `FOOTAGE` の3種（`map` / `store` / `cctv`）

## ニュースの作り（YouTube縦型ショートの文法）

テレビの画面キャプチャではなく、**スマホで見るニュースクリップ**として作ってある。

- 上部に**タイトルの座布団**（赤い縦帯＋見出し）を出しっぱなし
- 中央が**映像**
- 下部に**大きな焼き込み字幕**（白・太い黒フチ）― これが縦型ニュースの一番の特徴
- 情報プレート（身長・体格）は字幕のすぐ上
- セーフゾーン：左右5%（54px）・上下3%

字幕は n1 → n2a → n2b → n2c → n2d と進む。**枠は完全に同じで字幕だけが変わる**ので、
クロスフェードしても画がにじまない。喋りに合わせて切り替えると「再生されている」感じが出る。

**体重は言わない。** 実際の行方不明者のニュースは体重を出さない。「身長158センチくらい／
小柄で痩せ型」で**視聴者に小さい人だと思わせる**。47.2kg円と繋がるのは数字の一致ではなく
体格の印象 ― この作品の「説明しない」ルール通り。

### 中央の映像も描いてある

放送局が作りそうな**グラフィック**なので、写真ではなく図でいい。3段階で寄っていく：

| | 中身 |
|---|---|
| n1 | 夜の地図。赤いピンと「現場周辺」 |
| n2a | 夜の店舗外観。窓だけが白く光る |
| n2b 以降 | **防犯カメラのモザイク映像**「CAM 03」。通路の奥に人影らしい塊が1つ |

n2b が作品のラスト（CAM 04 の 94.4kg）と韻を踏む。ニュースがすでに
「防犯カメラに映った女性」を見せているので、最後に主人公が防犯カメラに映るとき、
視聴者は同じ画を2度目に見ることになる。

## 禁止

- 実在の企業・決済サービス・放送局の名称とロゴ
- 怪物・発光する目・異形・走る動作
- 文字が入る画像を生成モデルで作ること（ここで描く）
