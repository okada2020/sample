# 文字もの素材（生成モデルを使わない）

`build.py` が HTML を書いて headless Chromium で PNG に書き出す。日本語が崩れず、
毎回まったく同じレイアウトで、クレジットはかからない。

```
python3 build.py     # out/*.png
```

| ファイル | 用途 | サイズ |
|---|---|---|
| `screen_47_2kg.png` | レジ画面・異変（C4） | 900×1200 |
| `screen_1284.png` | レジ画面・正常に戻った（C7） | 900×1200 |
| `screen_scan.png` | スキャン中（C3） | 900×1200 |
| `receipt.png` | レシート「後ろを見ないでください」 | 620×1080 |
| `cctv_cam01.png` | 入店の防犯カメラ overlay | 1080×1920 透過 |
| `cctv_cam02.png` | 人影の防犯カメラ overlay | 1080×1920 透過 |
| `cctv_cam04_472.png` | 体重センサー 47.2kg | 1080×1920 透過 |
| `cctv_cam04_944.png` | 体重センサー 94.4kg | 1080×1920 透過 |
| `title.png` | タイトル＋ルール文 | 1080×1920 |

`screen_*` は映像の画面領域にトラッキング合成する。`cctv_*` は透過なので映像の上に重ねるだけ。
文言や数字を変えるときは `build.py` を直して再実行する。
