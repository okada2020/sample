# 文字もの素材（生成モデルを使わない）

`build.py` が HTML を書いて headless Chromium で PNG に書き出す。日本語が崩れず、
毎回まったく同じレイアウトで、クレジットはかからない。

```
python3 build.py     # out/*.png
```

## ニュースの作り（YouTube縦型ショートの文法）

テレビの画面キャプチャではなく、**スマホで見るニュースクリップ**として作ってある。

- 上部に**タイトルの座布団**（赤い縦帯＋見出し）を出しっぱなし
- 中央が**映像**
- 下部に**大きな焼き込み字幕**（白・太い黒フチ）— これが縦型ニュースの一番の特徴
- 情報プレート（身長・体格・服装）は字幕のすぐ上
- **体重は言わない。** 実際の行方不明者のニュースは体重を出さない。「身長158センチくらい／やせ型／小柄」で**視聴者に小さい人だと思わせる**。47.2kg円と繋がるのは、数字の一致ではなく体格の印象。この作品の「説明しない」ルール通り
- N2 は字幕違いの2枚（a→b）。実際のニュースクリップのように**喋りに合わせて字幕が変わる**ので、編集で切り替えると「再生されている」感じが出る
- セーフゾーン：左右5%（54px）・上下3%

`*_overlay.png` は**テロップ層だけの透過PNG**なので、下に好きな映像を敷ける。店の夜間外観でも、防犯カメラ映像でもよい。`news_n1.png` / `news_n2.png` は映像部分をプレースホルダにした確認用。

実在の放送局名・ロゴ・アプリのUIは入れていない。
