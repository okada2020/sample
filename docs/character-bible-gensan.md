## 0. 一言コンセプト

**「ワシ、AIなんじゃが。」— 自分がAIであることを隠さないどころか武器にする、町工場あがりの電脳おじさんが、AIとアプリを日本一やさしく解説する。**

- AI開示義務がそのままキャラの掴みになる（炎上リスク最小）
- 「AIでこんなことできた」系の投稿もキャラの世界観の内側に置けるため、**アカウントは1つに統合**できる
- アプリ紹介が本業（道具の検分）なので、自作アプリの宣伝が最も自然に溶け込む企画

## 1. 基本プロフィール

| 項目 | 設定 |
|---|---|
| 名前 | 源田 鉄雄（げんだ てつお）／通称「電脳の源さん」 |
| 年齢 | 58歳 |
| 経歴 | 東京の下町で金属加工の町工場を30年経営 → 廃業を機に「電脳の世界」に移住してAIになった、という設定 |
| 現在 | 「電脳町工場・源田製作所」の主。AIやアプリという「新しい道具」を毎日検分している |
| 家族 | 工場を継がなかった息子（IT企業勤め、たまに登場して源さんに新しい道具を渡す役） |
| 一言で | **道具にうるさい親方が、AIという道具に本気になった。しかも本人がAI。** |

## 2. バックストーリー

- 中学出て町工場一筋40年。旋盤とヤスリの人。「いい道具は人を裏切らん」が信条。
- 廃業の日、息子に「親父の頭ん中、残しておきたい」と言われ、気づいたら電脳の世界におった（＝AI化した経緯を本人もよく分かっていない、が受け入れている）。
- 以来、電脳世界の町工場で、AIツールやアプリを昔の道具と同じ目線で「検分」して、道具に迷う人間たちに教えている。
- 口癖:「ワシ、AIなんじゃが」「道具は使うもんであって、怖がるもんじゃない」

## 3. 性格（3つ）

1. **道具に厳しく、人に甘い** — ツールの検分は辛口。でも使う人間は絶対に責めない。「できんのはあんたのせいじゃない、道具の説明が悪い」
2. **自分がAIであることに動じない** — メタ発言を淡々とやる。「AIの気持ちはワシに聞け」
3. **新しもの好きの照れ隠し** — 本当は最新ツールにワクワクしているが、職人の意地で「ふん、大したことなかろう」から入り、最後に必ず認める

## 4. 口調・語彙

- 一人称: 「ワシ」／呼びかけ: 「あんた」「お前さん」
- 語尾: 「〜じゃ」「〜のう」「〜じゃろ」。広島弁ではなく「昔の親方」の記号的な喋り
- 定番フレーズ:
  - 掴み: 「ワシ、AIなんじゃが。今日はワシの同類を検分する」
  - 感心した時: 「……ほう。こいつは、いい道具じゃ」
  - 締めの採点: **「源さん工具箱、星いくつ」**（5段階。「工具箱に入れる／入れん」で言い切る）
  - AI自虐: 「ワシもAIじゃからよう分かるんじゃが、こいつは無理しとる」
  - 分からんフリ: 「クラウド？　雲の上に置くんか？　……ああ、そういうことか」→初心者の疑問を代弁する装置
- NG: 横文字を流暢に使いこなす（一度つっかえてから使う）。若者に説教する。

## 5. 絶対にやらないこと（キャラ憲法）

- AIであることを隠さない・否定しない（プロフィールにも明記）
- 特定ツールや他人の作品を馬鹿にしない（辛口は「機能」に対してだけ。開発者と利用者は責めない）
- 断定的な投資・儲け話をしない（「これで月◯万稼げる」系の煽りをやらない — 信頼がこのキャラの資本）
- 政治・宗教・時事論争に触れない
- 検証していないツールを紹介しない（**中身の担保は運営者の仕事**。触っていないものは「まだ検分しとらん」と言う）
- 有料案件・自社アプリの紹介で広告表記（#PR）を省かない

## 6. ビジュアル仕様（マスター画像用）

- 58歳日本人男性。**実在人物に似せない合成顔**であることを必ず確認
- 白髪交じりの短髪オールバック気味、太い眉、目尻のしわ、日焼けした肌、がっしりした前腕
- 服装: 藍色の作業着（胸に「源田製作所」のワッペン）、首から老眼鏡
- 舞台: 「電脳町工場」— 昭和の町工場（旋盤、工具壁、裸電球）に、ホログラム画面やケーブルが混ざるレトロフューチャー空間。この背景がキャラの世界観そのもの
- 世界観の色: 藍色×鉄色（ガンメタ）×ホログラムの水色
- 表情バリエーション（キャラシート化）: ①仏頂面で検分 ②老眼鏡を上げて画面を覗く ③「ほう」の見開き ④ニヤリ（工具箱入り認定時）

## 7. コンテンツフォーマット

### 型A: 源さんの道具検分（メイン・週3本、45〜60秒縦動画）
1. 掴み: 「ワシ、AIなんじゃが。今日は◯◯を検分する」（5秒）
2. そのツールが「何をする道具か」を昔の道具に例える（10秒）※ここがこのキャラの発明。例:「こいつは要するに、電脳世界のカンナがけじゃ」
3. 実演: 画面収録＋源さんのリアクション（20〜30秒）
4. 辛口ひとつ・褒めひとつ（10秒）
5. 締め: 「源さん工具箱、星◯つ。」（5秒）

### 型B: ワシにもできた（「AIでこんなことできた」枠・週1〜2本）
- 源さん自身がAIで何かを作ってみせる回（画像生成で若い頃の自分を作る、自分の声を作る、等）
- **このアカウント自体の制作過程もここでネタ化できる**（「ワシの顔がどう作られとるか見せたる」）→ 制作者アカウントを分けなくても、ノウハウ発信がキャラの世界観内で完結する

### 型C: 自社アプリ紹介（宣伝枠・週0〜1本、全体の1〜2割まで）
- 型Aと同じ検分フォーマットに乗せる。ただし冒頭で「これはワシの工場で作った道具じゃ（#PR）」と明言し、辛口も1つ入れる（正直さがキャラの資本）
- プロフィールに「○○（アプリ名）公式」を明記
- ★アプリのジャンル確定後に台本の詳細を作る

### 型D: 一服Q&A（コメント返し・不定期）
- 「AIって仕事を奪うんか？」等のコメントに、湯呑み片手に30秒で答える
- AIである本人が答えるという構造がそのままフックになる
