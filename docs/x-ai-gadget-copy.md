# 第1部：プロフィール

## 1-1. 表示名の候補（50文字以内）

| 案 | 表示名 | 狙い |
| --- | --- | --- |
| A | `AIガジェット検証室` | 「検証」で中立性を打ち出す。無難で強い |
| B | `ガジェ検／AIデバイスを実際に使う人` | 何をする人か即わかる |

**推奨：A または C。** 検索性と一貫性が高く、後からスマートグラス以外へ広げても破綻しません。
Dは短期の伸びは出やすいものの、1年後に改名が必要になります。

## 1-2. @ハンドルの候補

```
@ai_gadget_lab      @gadget_kenshou     @ai_device_check
@aigadget_note      @kenshou_gadget     @ai_gadget_jp
```
- **英数字とアンダースコアのみ／15文字以内**
- 既存の有名アカウントと紛らわしい名前は避ける（なりすまし判定のリスク）
- **既存アカウントと連想されるハンドルにしない**（複数アカウントの紐付けを避ける意味でも）

```
AIガジェットを実際に使って「買っていいか」を判定します｜スマートグラス・
AIデバイス中心／スペックより使用シーンで検証／忖度なし、買うなとも言います
／比較表は固定ポストに
```

### 案② 用途ベネフィット型
```
「そのAIガジェット、実際どこまで使えるのか」だけを検証しています｜
スマートグラス／AI文字起こし／AIアシスタント｜数値は全部自分で実測
｜レビュー依頼はDMへ
```

### 案③ 読者への約束型
```
AIデバイス選びで失敗しないための検証アカウント｜買う前に知りたかったことを
先に試します／良い点も無理な点も両方書く／比較まとめは固定ポスト
```

### 案④ 技術者スタンス型（制作スキルを匂わせる）
```
AIガジェットを実測で評価します｜遅延・精度・バッテリーは自分で計測／
スペック表の転載はしません｜スマートグラス・AI文字起こし・AIアシスタント
```

### 案⑤ 短文・余白型
```
AIガジェット、実際に使ってから言う人。
スマートグラス中心｜スペックより使用シーン｜買うなとも言う
```

**推奨：案①。** 「何を」「どう」「どんな姿勢で」の3点が入っていて、
**「買うなとも言う」が最大の差別化**として効きます。

### bio作成のチェックリスト
- [ ] 1行目に**ジャンルが明記**されている（アルゴリズムのジャンル分類に効く）
- [ ] **URLは入れない**（bioのリンクは可。ただし本文リンクは別問題）
- [ ] ハッシュタグを入れない
- [ ] 「駆け出し」「勉強中」を書かない（信頼の逆効果）

### A-2 【知識】【画像：チェックリスト1枚】
```
スマートグラスを買う前に確認する5項目

1. 度付きレンズに対応しているか
2. 1日の実使用でバッテリーが持つか
3. 日本語の音声認識精度
4. 屋外の明るさで画面が見えるか
5. 掛けたまま外を歩ける見た目か

残り4つは実際に使わないと分からない

### A-3 【意外性】
```
スマートグラス選びで一番効くスペック、実は「重さ」

50gと80gの差は、店頭の5分では分からない。
2時間で鼻に跡が残るかどうかで決まる。

解像度もAI精度も、掛け続けられなければ意味がない
```

### A-4 【まとめ】【画像：価格帯マップ】

AIガジェット、価格帯ごとに何が買えるか

〜1万円：AI文字起こしアプリ＋既存イヤホンで十分戦える
1〜3万円：単機能デバイス（録音・翻訳特化）

```

```
「AIスマートグラス」と「ARグラス」は別物

AIグラス：カメラとマイクでAIに聞く。画面は無いか最小限
ARグラス：目の前に映像を出す。AIはおまけ

求めているものが違うと確実に後悔する

### A-6 【共感】

知りたいのは「1週間使ったら結局どうだったか」なのに、
どこを見ても発売日の開封記事しかない

だからこのアカウントでは3か月後の再レビューまでやります
```

### A-7 【まとめ】【スレッド】

AI文字起こし、無料で試せる順に並べた

1. スマホ標準の音声入力 → 0円、精度は用途次第
2. AIアシスタントアプリの文字起こし → 0円〜
3. 有料の専用アプリ → 月◯円
4. 専用デバイス → ◯万円

いきなり4から入る人が多いけど、
1と2で足りるケースが結構ある

（各段階の実際の精度は下のスレッドで）

## D. 検証・合否判定（実機購入後・3か月目〜）

**このアカウントの主力**になる型です。テンプレートとして用意します。

### D-1 テンプレート：合否判定
```
【製品名】の【機能名】、【使用シーン】で使えるか試した

結論：【できたこと】は合格、【できなかったこと】は無理

・【数値1】
・【数値2】
・【定性的な所見】

「【スペック上できること】」と「【実際に使えること】」は別物だった
```

**記入例（数値は全て【要実測】）**
```
スマートグラスの同時通訳、会議で使えるか試した

結論：1対1の雑談は合格、複数人の会議は無理

・遅延 約【要実測】秒 → 相槌のタイミングがズレる
・複数人が被ると話者を取り違える
・単語単位の誤訳は文脈で補える範囲

「翻訳できる」と「会議で使える」は別物だった
```
