# x-account — Codex への指示

このフォルダは X アカウント @oka_chef_memo の運用に関する作業専用です。

## まず読むもの
- `X_RUNBOOK.md` — 方針・毎日の型・リプ相手の3層・検索クエリ・投稿ネタ30本・次の28日の手順・Codex用タスク（§10）。**このファイルが唯一の正**。Claude が更新するたびにこのリポジトリへプッシュされる。

## 役割分担
- Codex: 探す（リプ先の候補）・集計する（アナリティクス）・下書きを提案する
- 人間: リプライと投稿の最終文面を書き、投稿ボタンを押す
- Claude: 分析・戦略・ランブックの更新（§10-B のレポートを受け取って返信する）

## やらないこと（厳守）
- リプライ・投稿を自動投稿しない（下書き提案まで）
- フォロー／アンフォローを自動で行わない
- 温度・時間・分量など事実を含む文面を、裏取りなしに生成しない
- X のログイン情報を、このリポジトリや第三者サービスに書き込まない

## 下書きの受け渡し
- `drafts/YYYY-MM-DD_1100.md` ／ `_2130.md` に Claude が投稿案を置く（一覧は `drafts/README.md`）。**その日のファイルがあれば最優先で人間に提示する**（§10-D で新たに選ぶより先）。ファイルがない日だけ §10-D で §9 から選ぶ。
- 投稿されたら `posted.md` に記録し、その draft ファイルは残してよい。

## 定型タスク
`X_RUNBOOK.md` §10 を参照。
- A: リプ先を探す（毎日）
- B: 週次レポートを Claude に送る（毎週日曜 21:30 のリプ後。https://claude.ai/artifact/Adqjc58cDBkoKdQwG5jjPP にコメント →「Claudeに送る」。伸びた投稿TOP3／下位3も同じコメントに含める）
- D: 今日の投稿を用意する（毎日、11:00 と 21:30 の前）→ 使った DAY を `posted.md` に記録
