# 🍎 フルーツ転倒RTA（Fruit Tumble RTA）

> 果物を背負った少年が坂を駆け下りる。
> **自分から転ぶ**と背負った果物が前へ転がり出し、ゲートをくぐるたびに増え、
> 道をふさぐ動物を蹴散らす。転がり終わった果物は追いついて拾い直す。
> ゴールまでのタイムを競う。

`index.html` をブラウザで開くだけで遊べます（ライブラリ不要）。
1 枚で完結する配布版は `dist/fruit-tumble-rta.html`（ダブルクリックで起動）。

---

## 1. コンセプト

**一度転ぶ。こぼれた果物が壁になる。坂を駆け上がってくる動物の群れを、その壁で食い止める。**

- 少年はスタート直後に**一度だけ転ぶ**。こぼれた果物が前を転がりはじめ、これが**盾**になる。
- 果物は**ゲートをくぐるたびに増減**する。壁を厚くできるかはゲートの選び方次第。
- 動物は**わらわらと坂を駆け上がって**向かってくる。果物の壁にぶつかると、
  1 匹につき決まった数の果物と引き換えに弾き飛ばされる。
- 壁が足りないと**突破されて少年が転がされる**＝大きなタイムロス。
- ゴールまでの**タイム**を competing する RTA。止まらずに駆け抜けるほど速い。

---

## 2. 操作

| 操作 | 内容 |
|---|---|
| ドラッグ / ← → / A D | 左右に移動。**果物の壁も一緒に動く**ので、ゲートのどちら側を通すかを選ぶ |

操作はこれだけ。転ぶのは開始時の 1 回だけで、あとは壁の厚さと位置取りがすべて。

---

## 3. ゲームの流れ

```
走る ──▶ 転ぶ（果物 14 個がこぼれる）──▶ 起き上がる
                                          │
        ┌─────────────────────────────────┘
        ▼
   ゲートをくぐる（×3 / ÷2 …）──▶ 壁が増減
        │
        ▼
   動物の群れが向かってくる ──┬─ 壁が足りる → 1 匹ずつ弾き飛ばす（壁は減る）
                              └─ 足りない  → 突破され、少年が転がされて減速
        │
        ▼
      ゴール（タイム確定）
```

## 4. コースの要素

ゲートと敵の波が交互に並ぶ。コース長 470（ノーミスでおよそ 21 秒）。

| 要素 | 内容 |
|---|---|
| 🚪 ゲート | 左右 2 枚。通った側の演算が壁に適用される（`×2` `×3` `+20` / `÷2` `÷3` `-20` `-35`） |
| 🐗 ウリ坊 | 1 匹 2 個。数で押してくる |
| 🐵 サル | 1 匹 3 個 |
| 🐗 イノシシ | 1 匹 6 個。横幅が広い |
| 🐻 クマ | 1 匹 12 個。重い |

### 数字の設計
波の重さは **「ゲートを正しく選び続けたときの壁のおよそ 45%」** に置いてある
（15 → 21 → 28 → 37 → 48 → 63 → 83 → 108 → 140）。

- 正解を選び続ければ壁は増え続け、守り切れる
- **1 回まずい側（÷2 など）を踏むと次の波に届かなくなる**
- 突破されても、進行度に応じた下限（`8 + 進んだ距離×0.18`）まで箱からこぼれて立て直せる。
  ミスの代償は**失った時間**であって、走りが詰むことではない

ヘッドレス自動プレイの実測：ゲートを正しく選ぶボットで **23.8〜26.8 秒／突破 3〜6 回**。
ノーミスなら 21 秒台。

## 5. 絵づくり

キャラクターは **採用デザインの実画像をスプライトとして使用**（`assets/`）。
`design/CHARACTER-DESIGN.md` の絵柄ルール（太く滑らかな黒い輪郭線／ベタ塗り中心の
2Dトゥーン／グラデーション・光沢・写実表現の禁止）に、背景と UI も合わせている。

- 少年：走行中は **背面図**、転倒中は **転倒ポーズ**（果物が飛び散る絵）をそのまま使用
- 動物：正面図を使用。こちらへ向かって走ってくるので正面図が正しく機能する。
  壁にぶつかると回転しながら弾き飛ばされる
- 背景：空・雲・山・道はすべてベタ塗り＋黒い輪郭線。雲は黒を一回り大きく敷いて輪郭にしている
- 果物：ベタ塗りの円＋太い黒線。グラデーションと光沢は使わない

### スプライトの作り方
`design/` のラインナップ画像から、外周フラッドフィルで背景を透過し、
連結成分でキャラごとに切り出して縮小・減色したものが `assets/*.png`（10 枚・計 232KB）。

## 6. 技術メモ

- **依存ライブラリなし**。`index.html` + `game.js` + `assets/`。
- Canvas 2D の **1 点透視**（`project()`）。奥ほど沈む項を足して下り坂にしている。
- 画面比からカメラ高さと消失点を自動調整（縦長スマホ／横長 PC 対応）。
- スプライトはビルボード描画（`sprite()`）。奥行き順にソートして手前から描く。
- 効果音は WebAudio のオシレータ生成。音源ファイル不要。
- `node build.js` で `dist/fruit-tumble-rta.html`（スプライトを data URI で内包）を生成。
- QA 用フック `window.FruitRTA`（`state` / `start` / `dive` / `setX` / `pause`）。
