# 🍎 フルトリランナー（Furutori Runner）

> 果物を背負った少年が坂を駆け下りる。
> **自分から転ぶ**と背負った果物が前へ転がり出し、ゲートをくぐるたびに増え、
> 道をふさぐ動物を蹴散らす。転がり終わった果物は追いついて拾い直す。
> ゴールまでのタイムを競う。

`index.html` をブラウザで開くだけで遊べます（ライブラリ不要）。
1 枚で完結する配布版は `dist/fruit-tumble-rta.html`（ダブルクリックで起動）。

---

## 1. コンセプト

**坂の上で少年が転ぶ。こぼれた 3 個の果物が転がり出す ── それがプレイヤー。**

- 少年は**動かない**。転んだまま坂の上に残る。操作するのは**転がっていく果物**。
- ゲートをくぐるたびに数が増減する。**3 個が数十、数百に膨らむ**。
- 坂の下からは動物が**わらわらと駆け上がって**向かってくる。数の力で押し倒す。
- 果物がゼロになったら終わり。全部を抜けてゴールするまでの**タイム**を競う。

---

## 2. 操作

| 操作 | 内容 |
|---|---|
| ドラッグ / ← → / A D | 転がる果物を左右に動かす。ゲートのどちら側を通すか、どの動物にぶつけるかを選ぶ |

前進は自動（坂なので少しずつ速くなる）。避けるか、ぶつけるかの判断だけ。

---

## 3. 敵の強さ

**強さ＝倒すのに必要な果物の数**。当たった数だけ相手の体力が削れ、削り切れないと果物が尽きる。

| 動物 | 必要な果物 | 性格 |
|---|---|---|
| 🐗 ウリ坊 | **1 個** | 小さくて速い。数十匹でわらわら来る |
| 🐵 サル | **1 個** | 同上。少し速い |
| 🐗 イノシシ | **10 個** | 横幅が広い。避けにくい |
| 🐻 クマ | **50 個** | 重い。数がそろっていないと押し負ける |

動物はほぼ自分のレーンを走ってくるので、**大物は避けて通ることもできる**。
倒すか避けるかの判断がタイムに効く。

---

## 4. 数字の設計

果物が青天井に増えるとクマの 50 個が意味を失うため、**上限 400 個**を設けている。

- `EXPECT[i] = 9 × 1.36^i`（上限 400）を「その地点での想定数」として、
  **ゲートの中身も敵の波の重さも、すべてこの値から自動生成**している
  - 当たり：`×2` または `+（想定数の 70%）`
  - はずれ：`÷2` または `-（想定数の 45%）`（ゲートでは 0 にはならない）
- 波の重さ＝`(想定数 × 0.45 + 今の数 × 0.55) × 0.55`。
  **出るときに今の数を見て決める**ので、上手く育てた人にはそれなりの相手が出る
- 重さから出す動物を決める：軽い波は 1 個で倒せる小物が数十匹、
  重い波はイノシシ、いちばん重い波はクマの群れ

出だしの 2 枚のゲートは**両側とも当たり**。3 個をまず育ててから戦わせる。

ヘッドレス自動プレイの実測（ゲートの得な側を選び続けるボット）：
**30 秒前後でゴール、倒した数 127、最大 400 個**。1 枚まずい側を踏むと立て直しに 2 枚かかる。

## 5. 絵づくり

キャラクターは **採用デザインの実画像をスプライトとして使用**（`assets/`）。
`design/CHARACTER-DESIGN.md` の絵柄ルール（太く滑らかな黒い輪郭線／ベタ塗り中心の
2Dトゥーン／グラデーション・光沢・写実表現の禁止）に、背景と UI も合わせている。

- 少年：走行中は **背面図**、転倒中は **転倒ポーズ**（果物が飛び散る絵）をそのまま使用
- 動物：正面図を使用。こちらへ向かって走ってくるので正面図が正しく機能する。
  壁にぶつかると回転しながら弾き飛ばされる
- 背景：空・雲・山・道はすべてベタ塗り＋黒い輪郭線。雲は黒を一回り大きく敷いて輪郭にしている
- 果物：ベタ塗りの円＋太い黒線。グラデーションと光沢は使わない

### スプライトの作り方
`design/` のラインナップ画像から、外周フラッドフィルで背景を透過し、
連結成分でキャラごとに切り出して縮小・減色したものが `assets/*.png`（10 枚・計 232KB）。

## 6. 技術メモ

- **依存ライブラリなし**。`index.html` + `game.js` + `assets/`。
- Canvas 2D の **1 点透視**（`project()`）。奥ほど沈む項を足して下り坂にしている。
- 画面比からカメラ高さと消失点を自動調整（縦長スマホ／横長 PC 対応）。
- スプライトはビルボード描画（`sprite()`）。奥行き順にソートして手前から描く。
- 効果音は WebAudio のオシレータ生成。音源ファイル不要。
- `node build.js` で `dist/fruit-tumble-rta.html`（スプライトを data URI で内包）を生成。
- QA 用フック `window.FruitRTA`（`state` / `start` / `dive` / `setX` / `pause`）。
